# Title: Trajectory Chord Regularization for Linearly Connected Character Language Models
# Experiment description: Keep the GPT architecture, data loader, ordinary next-character cross-entropy objective, evaluation path, and generation code unchanged. In train(), disable torch.compile for this experiment or use the uncompiled raw_model handle, and maintain a small CPU fp16 buffer of recent late-training snapshots, storing 4 to 8 state_dict copies after a chord_start fraction such as 0.3 or 0.5 of max_iters. On ordinary iterations, train exactly as the baseline. After chord_start and every chord_interval steps, first compute the normal current-model CE loss on the batch. Then sample one stored snapshot and an interpolation coefficient alpha biased near the current model, such as Uniform(0.1, 0.5). Temporarily replace each floating trainable parameter by (1 - alpha) * current_param + alpha * snapshot_param, run one auxiliary forward on the same batch, and add a conservative ramped chord loss consisting of temperature-2 KL from detached current logits to chord logits plus optional chord CE. Scale the chord loss by (1 - alpha) and restore the exact current parameters before optimizer.step. Add diagnostics that evaluate validation loss along interpolation chords between the final model and stored snapshots, reporting mean and maximum loss barriers. Compare baseline training, late SWA evaluation, local weight-jitter consistency, and trajectory chord regularization across shakespeare_char, enwik8, and text8. Report best validation loss, train-val gap, interpolation barrier, expected calibration error, seed variance, total train time, and unchanged generation tokens per second.
