# Title: Counterfactual Gradient Agreement for Prefix-Robust Character Language Modeling
# Experiment description: Modify GPT.forward() to optionally return final hidden states after ln_f. Add make_rolled_prefix_view(X, Y, suffix_len) that preserves a recent suffix such as the final 96 or 128 tokens while replacing only the older prefix with rolled same-batch prefixes. Add compact_output_gradient_sketch(logits, hidden, targets, R_vocab, R_hidden), which approximates the suffix output-layer gradient by projecting residuals softmax(logits) - one_hot(target) with R_vocab, projecting hidden states with R_hidden, averaging their outer product over protected suffix positions, and flattening one sketch per sequence. Train every iteration with ordinary clean next-character cross-entropy. After warmup_iters and every agreement_interval iterations, run one rolled-prefix forward pass on the same batch, compute clean and counterfactual suffix sketches, detach the clean sketch, and add a small ramped hinge loss relu(margin - cosine(clean_sketch, counterfactual_sketch)). Weight the hinge by a detached gate based on counterfactual suffix NLL increase, so examples whose older prefix genuinely changes the prediction contribute little. Keep generation and ordinary evaluation unchanged. Extend estimate_loss() to report clean validation loss, rolled-prefix validation loss, gradient-sketch agreement, clean-to-rolled degradation, suffix loss by distance from prefix boundary, train-val gap, total train time, and unchanged generation tokens per second. Compare against the baseline, rolled-prefix KL consistency, rolled-prefix CE-only augmentation, and shuffled-suffix sketch controls across shakespeare_char, enwik8, and text8.
