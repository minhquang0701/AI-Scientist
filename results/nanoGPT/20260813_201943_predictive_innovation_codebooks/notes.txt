# Title: Predictive Innovation Codebooks for Discrete Autoregressive Belief Updates
# Experiment description: Keep the GPT architecture, data loader, ordinary evaluation path, and generation code unchanged. After loading each dataset vocabulary, create a fixed zero-mean normalized random projection matrix R from vocab_size to a small innovation_dim such as 32 or 64, and add a train-only learnable innovation codebook with 8, 16, or 32 vectors. In train(), always optimize standard next-character cross-entropy. After warmup_iters and every innovation_interval iterations, reuse the same logits from the normal forward pass, compute probs = softmax(logits), and form adjacent predictive innovation sketches delta_t = (probs[:, 1:, :] - probs[:, :-1, :].detach()) @ R, ignoring the first few positions for stability. Assign each detached delta_t to its nearest codebook vector and add a small ramped VQ-style auxiliary loss: ||delta_t - code.detach()||^2 + ||delta_t.detach() - code||^2. Optionally downweight the auxiliary for very high-surprisal observed tokens so rare large updates are not over-compressed. Extend estimate_loss to report ordinary train/validation loss as the primary metric, innovation reconstruction error, code usage entropy, dead-code fraction, predictive update norm by observed-surprisal bucket, expected calibration error, train-val gap, total train time, and unchanged generation tokens per second. Compare against the baseline, continuous L2 update-smoothing, random code assignments, and multiple codebook sizes across shakespeare_char, enwik8, and text8.
