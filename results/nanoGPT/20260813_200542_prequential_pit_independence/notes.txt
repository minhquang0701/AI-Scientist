# Title: Prequential PIT Independence for Sequentially Calibrated Character Language Models
# Experiment description: Keep the GPT architecture, optimizer, data loader, evaluation path, and generation code unchanged. After loading each dataset vocabulary, create a small fixed set of random vocabulary permutations. Add a midpoint_pit_values(logits, targets, permutations) helper that computes differentiable discrete PIT values u_t by summing model probability mass before the target under each permutation plus 0.5 times the target probability. Train with ordinary next-character cross-entropy as the primary loss. After warmup_iters and every pit_interval iterations, softly assign PIT values to a small number of bins such as 8, detach the previous-time bin assignments, and penalize lagged dependence for lags such as 1, 2, and 4 by comparing the empirical previous-bin/current-bin joint matrix to the product of its marginals with a squared error. Use a conservative ramped auxiliary weight such as lambda_pit in {0.005, 0.01, 0.05}. Extend estimate_loss to report ordinary train and validation NLL as the primary metric, marginal PIT uniformity error, lagged PIT dependence error, randomized-PIT diagnostic error, expected calibration error, Brier score, validation loss by confidence bucket, train-val gap, total train time, and unchanged generation tokens per second. Compare against the baseline, marginal-only PIT calibration, uniform label smoothing, learned global temperature, and shuffled-lag PIT controls across shakespeare_char, enwik8, and text8.
