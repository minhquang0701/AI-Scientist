# Title: Surprisal-Gated Residual Curvature for Stable Autoregressive Transformer Dynamics
# Experiment description: Modify GPT.forward() to optionally return the residual stream after the embedding dropout and after each transformer block, while keeping the default training, evaluation, and generation path unchanged. Add a residual_curvature_loss(layer_hiddens, logits, targets) helper. For each layer, define the residual update u_l,t = h_{l+1,t} - h_{l,t}; then measure temporal update curvature as ||u_l,t+1 - u_l,t||^2 normalized by the detached RMS of u_l. Compute detached observed-token surprisal from the model's ordinary logits, aligned so the surprisal of the newly observed token controls how much the next residual-update change is penalized. Low-surprisal transitions receive a tight curvature budget, while high-surprisal transitions receive a loose budget or zero weight. In train(), optimize ordinary next-character cross-entropy on every iteration; after warmup_iters, every curvature_interval iterations, request layer hidden states and add a small ramped hinge penalty mean(relu(curvature - budget)^2), optionally subsampling positions and layers for speed. Extend estimate_loss() to report ordinary train/validation loss as the primary metric, residual curvature, budget violation rate, validation loss by observed-surprisal bucket, train-val gap, total train time, and unchanged generation tokens per second. Compare against the baseline, ungated residual-curvature regularization, direct hidden-state smoothing, and a shuffled-surprisal-budget control across shakespeare_char, enwik8, and text8.
