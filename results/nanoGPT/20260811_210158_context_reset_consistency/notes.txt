# Title: Context-Reset Consistency for Nonstationarity-Robust Character Language Modeling
# Experiment description: Add a spliced-batch auxiliary mode after warmup_iters. Sample two independent chunks A and B of length block_size + 1, choose a boundary b such as 64, 128, or 192, and form chunk_splice = concat(A[:, :b], B[:, :block_size + 1 - b]). Set X_splice = chunk_splice[:, :-1] and Y_splice = chunk_splice[:, 1:], masking Y_splice[:, b - 1] = -1 because the first token after the splice is not predictable from the old context. Train the ordinary clean next-token cross-entropy every iteration. On reset_interval iterations, run the model on X_splice and also on the unspliced B prefix; add spliced cross-entropy plus a small ramped KL loss that matches spliced logits after the boundary to detached reset-context logits from B for the first K post-boundary positions. Extend estimate_loss() to report clean validation loss, spliced validation loss, reset-consistency KL, and post-shift recovery loss by distance from the boundary. Compare against the baseline, spliced CE without consistency, and a compute-matched extra-batch control across shakespeare_char, enwik8, and text8. Report best clean validation loss, post-shift recovery curves, clean-to-spliced degradation, train-val gap, total train time, and unchanged generation tokens per second.
