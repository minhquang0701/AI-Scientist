# Title: Sampled Attention Commutation for Stable Multi-Hop Context Routing
# Experiment description: Modify CausalSelfAttention.forward to optionally return attention probabilities, using the manual causal attention path only when return_attention=True while preserving the default flash-attention path for ordinary training, evaluation, and generation. Propagate return_attention through Block.forward and GPT.forward. Add sampled_attention_commutator_loss(attn_maps, band_edges, max_queries, max_heads), which samples a small set of adjacent layer pairs, heads, and suffix query positions. For each selected query row, compute only the row-wise two-hop distributions A_next[q] @ A_prev and A_prev[q] @ A_next, avoiding full attention-matrix products. Aggregate each two-hop distribution into logarithmic causal distance bands such as 0-3, 4-15, 16-63, 64-127, and 128-255, then penalize symmetric KL or squared Hellinger distance between the two band distributions. In train(), optimize ordinary next-character cross-entropy on every iteration; after warmup_iters, every commutation_interval steps, request attention maps and add a small ramped lambda_commute times the commutator loss. Evaluation and generation use the unchanged default forward path. Extend diagnostics to report ordinary train and validation loss, attention commutator divergence, validation loss at context lengths 32, 64, 128, and 256, repeated-target versus novel-target loss, train-val gap, total train time, and unchanged generation tokens per second. Compare against the baseline, a manual-attention no-regularizer control, attention distance-coverage regularization, and a shuffled-layer-pair commutation control across shakespeare_char, enwik8, and text8.
