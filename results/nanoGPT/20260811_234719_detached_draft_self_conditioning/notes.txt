# Title: Detached Draft Self-Conditioning for Iterative Causal Language Modeling
# Experiment description: Add an optional second-pass self-conditioning path to GPT. Extend GPTConfig with use_draft_conditioning, draft_temperature, draft_interval, lambda_draft_max, and draft_gate_init. In GPT.__init__, add draft_proj = Linear(n_embd, n_embd) and a learned scalar draft_gate initialized to 0.0. Modify GPT.forward(idx, targets=None, draft_logits=None, return_full_logits=False) so the default path is unchanged. When draft_logits is provided, detach it, compute softmax(draft_logits / draft_temperature), form expected next-token embeddings with probs @ transformer.wte.weight.detach(), project them with draft_proj, and add draft_gate * projected_draft_embedding to token embeddings before positional embeddings. In training, always compute the ordinary one-pass next-token cross-entropy. After warmup_iters, every draft_interval iterations, run a second refined pass using detached first-pass logits and optimize total_loss = one_pass_loss + lambda_draft * refined_loss, with lambda_draft ramped up to 0.25 or 0.5. Extend estimate_loss to report one-pass validation loss, refined two-pass validation loss, refined-minus-one-pass improvement, and prediction agreement. Keep ordinary generation unchanged, and add an optional refined generation diagnostic that performs one draft pass and one refined pass per generated token. Compare against the baseline, a zero-draft adapter control, and a shuffled-draft control across shakespeare_char, enwik8, and text8, reporting best validation loss, train time, and one-pass versus refined inference tokens per second.
