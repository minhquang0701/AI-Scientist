# Title: Role-Factorized Output Embeddings for Asymmetric Character Language Modeling
# Experiment description: Modify GPT so the tied output matrix can optionally be relaxed by a small low-rank residual: W_out = W_token + scale * A @ B, where W_token is transformer.wte.weight. Initialize A randomly, B to zeros, and scale to a small nonzero value so the model starts exactly as the tied baseline while gradients can still enter the residual branch. Add GPTConfig fields use_role_factorized_output, output_residual_rank, output_residual_scale_init, and output_residual_l2. Replace direct lm_head calls with a helper that computes logits from the effective output matrix, while keeping the default tied path unchanged. Compare the original tied baseline, a fully untied output head, and low-rank residual ranks such as 4, 8, 16, and 32. Keep the ordinary next-character cross-entropy objective, optimizer, data loader, evaluation loop, and generation procedure unchanged. Extend logging to report parameter count, best validation loss, final train loss, train-val gap, inference tokens per second, residual norm, effective input-output embedding cosine drift, rare-token validation loss, and repeated-versus-novel target loss. The hypothesis is that small autoregressive character models benefit from controlled asymmetry between input-token representation and output-token prediction roles without the parameter cost or overfitting risk of a fully untied classifier.
