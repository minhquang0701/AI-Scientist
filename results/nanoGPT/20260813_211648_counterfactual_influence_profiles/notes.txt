# Title: Counterfactual Influence Profiles for Long-Context Credit Assignment
# Experiment description: Modify GPT.forward() to optionally return final hidden states after ln_f. Add a training-only influence_profile_head Linear(n_embd, num_distance_buckets) that predicts, for each protected suffix position, how much earlier context from each logarithmic distance bucket affects that prediction. Train with ordinary next-character cross-entropy on every iteration. After warmup_iters and every influence_interval iterations, use a protected suffix such as the final 64 tokens. For each distance bucket, create one counterfactual batch by replacing one sampled earlier token per sequence with the token at the same position from another batch element, preserving sequence length. Under torch.no_grad(), compare clean and counterfactual true-target NLL on the protected suffix, clip positive NLL increases, and normalize them within the batch to form detached influence-profile targets. Run the clean batch with return_hidden=True and add a small ramped Huber loss from influence_profile_head(hidden_suffix) to these targets, with lambda_influence around 0.02 to 0.10. Evaluation and generation ignore the auxiliary head and use the standard lm_head unchanged. Extend estimate_loss() to report ordinary validation loss as the primary metric, influence-profile MSE or rank correlation on validation probes, repeated-target versus novel-target loss, validation loss by previous-occurrence distance bucket, train-val gap, total train time, and unchanged generation tokens per second. Compare against the baseline, random influence targets, distance-only targets without counterfactual measurement, and a detached-hidden auxiliary-head control.
