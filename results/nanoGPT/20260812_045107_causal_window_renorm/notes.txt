# Title: Causal Window Renormalization for Nonstationary Autoregressive Transformers
# Experiment description: Add an optional CausalWindowRenorm adapter inside each transformer Block after the attention residual and before the MLP. The adapter computes feature-wise causal running mean and variance over a bounded recent window such as 64 or 128 tokens using torch.cumsum, forms normalized deviations z_t = (x_t - mean_window_t) / sqrt(var_window_t + eps), optionally detaches the statistics for stability, projects z_t back to n_embd with a Linear layer, applies dropout, and adds the result through a learned scalar gate initialized near zero. Extend GPTConfig with use_window_renorm, renorm_window_size, renorm_gate_init, renorm_eps, and detach_renorm_stats. Keep the data loader, next-character cross-entropy objective, optimizer, evaluation loop, and generation API unchanged. Compare the baseline, causal window renorm with window sizes 64 and 128, a parameter-matched residual adapter without causal statistics, and a batch-shuffled-statistics control across shakespeare_char, enwik8, and text8. Report ordinary train and validation loss, best validation loss, train-val gap, learned gate values by layer, validation loss under simple prefix-splice distribution shifts, parameter count, total train time, and inference tokens per second.
