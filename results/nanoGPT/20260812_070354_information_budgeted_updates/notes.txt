# Title: Information-Budgeted Predictive Updates for Stable Autoregressive Language Modeling
# Experiment description: Keep the GPT architecture, data loader, optimizer, evaluation path, and generation code unchanged. In the training loop, compute the ordinary next-token cross-entropy as the primary loss. After warmup_iters, add a no-extra-forward predictive update penalty from the same logits. Let p_prev be the detached predictive distribution from logits[:, :-1] before observing X[:, 1:], and let p_cur be the predictive distribution from logits[:, 1:] after observing those tokens. Compute normalized observed_surprisal = -log p_prev[X[:, 1:]] / log(vocab_size) and normalized previous_entropy = entropy(p_prev) / log(vocab_size). Measure adjacent predictive drift with Jensen-Shannon divergence between p_prev and p_cur. Define a detached allowed budget = base_budget + surprise_slope * observed_surprisal + entropy_slope * previous_entropy, and add mean(relu(js_drift - allowed_budget)^2) with lambda_update ramped to small values such as 0.005, 0.01, and 0.02. Ignore the first few positions for stability. Compare against the baseline, fixed-budget temporal smoothing, and a shuffled-budget control across shakespeare_char, enwik8, and text8. Extend estimate_loss() to report ordinary train/validation loss as the primary metric, mean JS drift, budget violation rate, expected calibration error, validation loss by surprise bucket, train-val gap, total train time, and unchanged inference tokens per second.
