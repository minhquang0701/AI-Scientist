# Title: Evidence-Gated Prefix Bottlenecks for Predictive-Sufficient Character Language Modeling
# Experiment description: Modify GPT.forward to optionally return final hidden states after ln_f. Add a small PrefixSketchAdversary trained through a gradient-reversal layer to predict simple target-independent summaries of the older prefix, such as a salted rolling-hash bucket and a coarse character-count bucket, from hidden states in a protected suffix. Train ordinary full-context next-character cross-entropy on every iteration. After warmup_iters and every bottleneck_interval, run the normal full-context forward with return_hidden=True, then run one no-grad short-context forward on X[:, -L:], Y[:, -L:] with L=64 or 128. Align suffix positions and compute detached evidence_gain = short_context_nll - full_context_nll. Apply the adversarial bottleneck only where evidence_gain is small, so the model is discouraged from encoding old-prefix details only when the old prefix does not improve prediction. Optimize ce_loss plus a conservatively ramped lambda_bottleneck times the gated adversarial loss. Extend estimate_loss to report ordinary validation loss, short-context validation loss, prefix-sketch probe accuracy on low-evidence versus high-evidence positions, validation loss under prefix replacement, repeated-target versus novel-target loss, and train-val gap. Compare against the baseline, unconditional prefix adversary, random evidence gates, prefix-replacement consistency, and short-context dropout across shakespeare_char, enwik8, and text8.
