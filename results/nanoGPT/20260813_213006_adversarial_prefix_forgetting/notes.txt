# Title: Adversarial Prefix Forgetting for Predictive-Sufficient Character Language Models
# Experiment description: Modify GPT.forward() to optionally return final hidden states after ln_f. Add a small train-only PrefixHashAdversary MLP with multiple independent hash heads and a gradient-reversal helper. Implement compute_old_prefix_hash_labels(X, suffix_len=96, burnin=16, num_hashes=4, num_buckets=128), which uses fixed salted rolling hashes of only the older prefix before the protected suffix and assigns those hash labels to later suffix positions after the burn-in. In train(), keep ordinary next-character cross-entropy as the primary objective on every iteration. After warmup_iters and every prefix_adv_interval iterations, run the normal forward pass with return_hidden=True, select protected suffix hidden states, feed them through gradient reversal into the adversary, and add a weak ramped adversarial hash loss with lambda_prefix_adv in a conservative range such as 0.005 to 0.05. Compare the baseline, adversarial prefix forgetting, non-adversarial prefix-hash prediction, shuffled-hash adversarial control, and a hidden-norm penalty control across shakespeare_char, enwik8, and text8. Extend estimate_loss() to report ordinary validation loss, train-val gap, adversary hash accuracy, detached post-hoc prefix-hash probe accuracy, validation loss under far-prefix replacement, suffix loss by distance from replacement boundary, long-distance repeated-target loss, total train time, and unchanged generation tokens per second.
