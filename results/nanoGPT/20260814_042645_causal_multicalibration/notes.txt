# Title: Causal Multicalibration for Character-Level Language Models
# Experiment description: Keep the GPT architecture, data loader, optimizer, evaluation path, and generation code unchanged. Add build_causal_groups(X, logits_detached), assigning each valid batch-time position to a compact fixed set of groups using only visible context and detached predictions: absolute-position buckets, predictive-entropy buckets, max-probability buckets, recent-context diversity buckets, current-input-token frequency buckets, and a few intersections such as position by confidence and local-diversity by confidence. Add causal_multicalibration_loss(logits, targets, groups, vocab_size), which computes probabilities from logits and, for each group with enough valid positions, compares the group's mean predicted vocabulary distribution to the empirical target histogram for that group using Jensen-Shannon divergence. Train with ordinary next-character cross-entropy on every iteration; after warmup_iters and every calibration_interval iterations, add a small ramped lambda_cal times this group calibration loss, with lambda_cal values such as 0.005, 0.01, and 0.05. Extend estimate_loss to report ordinary train and validation NLL as the primary metric, group calibration error, worst-group validation loss, ECE, Brier score, validation loss by position/confidence/context-diversity buckets, train-val gap, total train time, and unchanged generation tokens per second. Compare against the CE-only baseline, global distribution calibration with one all-token group, confidence-bin-only calibration, uniform label smoothing, and random group assignments across shakespeare_char, enwik8, and text8.
