# Title: Causal Boundary-Age Embeddings for Tokenizer-Free Language Models
# Experiment description: Extend GPTConfig with use_boundary_age_embeddings, boundary_age_num_buckets, boundary_age_gate_init, and boundary_token_ids. In train(), after loading meta.pkl, derive at most two simple boundary classes from characters present in the dataset: separators such as space, newline, and tab, and punctuation such as period, comma, colon, semicolon, quotes, brackets, question marks, and exclamation marks. Skip any unavailable class. In GPT.__init__, add a compact learned boundary-age embedding table for each active class and one learned scalar gate per class initialized near zero. Modify GPT.forward() so that, when enabled, it computes the causal distance from each position to the most recent earlier-or-current token in each boundary class using vectorized cumulative maxima, maps distances into capped logarithmic buckets, sums the gated boundary-age embeddings, and adds them to token embeddings before positional embeddings. Keep the ordinary next-character cross-entropy objective, optimizer, evaluation loop, and generation API unchanged. Compare the baseline, boundary-age embeddings, a frequency-matched random-boundary control, and a separator-only ablation across shakespeare_char, enwik8, and text8. Extend estimate_loss() to report ordinary train/validation loss, validation loss by distance-to-boundary bucket, learned gate values, total train time, and inference tokens per second. The key test is whether lightweight causal structural coordinates improve tokenizer-free language modeling without external data, auxiliary labels, sparse attention, or changed supervision.
