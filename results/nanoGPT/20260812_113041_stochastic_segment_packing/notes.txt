# Title: Stochastic Segment Packing for Granularity-Robust Character Language Models
# Experiment description: Modify GPT.forward to optionally accept inputs_embeds and position_ids while preserving the default idx path used for ordinary training, evaluation, and generation. Add a small learned span_length_embedding table for lengths 1 to 6. During training, always compute the standard full character-level next-token cross-entropy. After warmup_iters, every packing_interval iterations, build an auxiliary packed view of the same batch: keep a protected recent suffix such as the final 128 tokens uncompressed, randomly segment the older prefix into spans of length 1 to 6 using one shared stochastic packing pattern per batch, replace each span by the mean of its token embeddings plus the corresponding span-length embedding, and assign that packed token the original position id of the span's final character. Append the ordinary suffix token embeddings, set targets to -1 for packed-prefix positions while keeping normal next-character targets on the suffix positions, and run the packed sequence through the model. Add a ramped auxiliary loss on the packed view consisting of suffix cross-entropy plus an optional small temperature-2 KL consistency term from detached clean full-context suffix logits to packed-view suffix logits. Extend estimate_loss to report clean validation loss, packed-suffix validation loss at fixed compression ratios, clean-to-packed degradation, compression ratio, and loss by distance from the packed-prefix boundary. Compare the baseline, packed-view CE only, packed-view CE plus KL consistency, and a suffix-only no-prefix control across shakespeare_char, enwik8, and text8. Report best clean validation loss, packed-context robustness, train-val gap, total train time, and unchanged ordinary generation tokens per second.
