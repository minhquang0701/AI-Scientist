# Title: Exposure-Normalized Key-Load Regularization for Sink-Resistant Attention
# Experiment description: Modify CausalSelfAttention.forward to accept optional load_regularize, local_window, and load_ratio_cap arguments. When disabled, keep the existing flash-attention path unchanged. When enabled on scheduled auxiliary iterations after warmup_iters, use the manual causal attention path and compute attention probabilities. Mask out self and recent local keys within local_window. For each layer and head, compute the actual nonlocal load received by each key position, and compute an exposure-matched expected load by redistributing each query's total nonlocal attention mass uniformly over its eligible nonlocal keys. Penalize only excessive concentration, for example mean(expected_load * relu(actual_load / (expected_load + eps) - load_ratio_cap)^2), so naturally high-exposure early positions and low-nonlocal-mass heads are not over-penalized. Ramp lambda_load from 0 to small values such as 0.001, 0.005, and 0.01 while keeping ordinary next-character cross-entropy dominant. Extend logging and estimate_loss to report ordinary validation loss, exposure-normalized top-key load ratio, attention mass on early crop-boundary tokens, validation loss by absolute position bucket, validation losses at context lengths 32, 64, 128, and 256, train-val gap, total train time, and unchanged default generation tokens per second. Compare the flash-attention baseline, a manual-attention no-regularizer control, row-wise attention entropy regularization, and exposure-normalized key-load regularization across shakespeare_char, enwik8, and text8.
