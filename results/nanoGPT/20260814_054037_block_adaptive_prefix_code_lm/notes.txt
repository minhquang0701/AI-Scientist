# Title: Block-Local Adaptive Prefix Codes for Lossless Character Language Modeling
# Experiment description: Implement a block-local deterministic adaptive prefix-code view for each dataset. Before training, compute a smoothed train-set unigram prior. In get_batch(), sample raw character chunks, reset a canonical 4-ary prefix-code codec to this prior at the start of each chunk, encode characters sequentially, update counts only after each character is fully emitted, and rebuild the code at fixed decoded-character intervals such as 16 or 32. Return fixed-length code-symbol X and Y plus a validity mask for the current partial codeword, so the training loss masks invalid next code symbols before cross-entropy. Train the existing GPT on code-symbol prediction with vocab_size equal to 4, leaving the raw-character baseline unchanged. Extend evaluation to report negative log likelihood per decoded character, code-symbol loss, average code symbols per character, effective decoded context length, generation validity, decoded-character generation speed, and sample diagnostics. Compare raw character GPT, fixed train-set Huffman coding, block-local adaptive prefix coding with a small sweep over rebuild interval and smoothing, and a length-shuffled fixed-code control. Include equal-code-token and decoded-context-matched comparisons where practical.
