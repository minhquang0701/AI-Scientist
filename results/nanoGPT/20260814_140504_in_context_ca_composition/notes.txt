# Title: In-Context Cellular Automata for Local Rule Composition in Character Language Models
# Experiment description: Add a get_ca_batch(vocab_size, batch_size, block_size, device) helper that generates synthetic auxiliary sequences using only token ids from the current dataset vocabulary. Each sequence chooses two state symbols and a few separator symbols, encodes an elementary cellular automaton rule as 8 binary state symbols in the prefix, then writes row_0, row_1, ..., row_K where each next row is produced from the previous row using cyclic boundary conditions. Construct X and Y normally, but set targets to -1 for rule tokens, separators, and the initial row, so loss is applied only to evolved-row state symbols. Use a simple curriculum that starts with short rows and one-step evolution, then increases row length and rollout depth. In train(), keep ordinary real-text next-character cross-entropy every iteration; after warmup_iters, every ca_interval iterations add one auxiliary CA batch with total_loss = lm_loss + lambda_ca * ca_loss, ramping lambda_ca conservatively to 0.05 to 0.15. Extend diagnostics to report ordinary validation loss as the primary metric, CA accuracy on trained rules, held-out elementary rules, held-out symbol remappings, and rollout depths longer than those used in training. Compare the baseline, CA curriculum, shuffled-rule controls, random synthetic controls, and one-step-only CA ablations across shakespeare_char, enwik8, and text8. Generation remains unchanged and uses the normal character LM path.
