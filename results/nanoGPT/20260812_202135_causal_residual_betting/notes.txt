# Title: Causal Residual-Betting Calibration for Autoregressive Language Models
# Experiment description: Keep the GPT architecture, data loader, ordinary next-character cross-entropy objective, evaluation path, and generation code unchanged. After loading each dataset's vocab_size, create a fixed random projection matrix R from token ids to a small residual sketch dimension such as 16 or 32. On auxiliary iterations after warmup_iters, compute logits, probabilities, and projected forecast residuals e_t = R[target_t] - probs_t @ R for valid targets. Add a small train-only ResidualBettor MLP that receives leakage-free causal features: detached current forecast entropy, max probability, absolute position bucket, and shifted EMA summaries of past projected residuals over windows such as 8, 32, and 128. First train the bettor with an MSE loss to predict detached e_t from these causal features. Then update GPT with ordinary CE plus a small ramped calibration penalty that discourages the current residual from aligning with the detached bettor prediction, for example mean((sum(bettor_pred.detach() * e_t, dim=-1))^2), using lambda_bet values such as 0.001, 0.005, and 0.01 every betting_interval iterations. Extend estimate_loss to report ordinary train and validation NLL as the primary metric, held-out bettor residual-prediction MSE, residual betting score, expected calibration error, Brier score, residual autocorrelation by lag, validation loss by predictive-entropy bucket, train-val gap, total train time, and unchanged generation tokens per second. Compare against the baseline, uniform label smoothing, learned global temperature, fixed martingale residual whitening, and a shuffled-past-feature bettor control across shakespeare_char, enwik8, and text8.
