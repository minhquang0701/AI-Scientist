# Title: Position-Scale Consistency for Length-Robust Character Transformers
# Experiment description: Separate supervised sequence length from positional capacity: keep training windows at 256 tokens but initialize GPTConfig.block_size to 512. Modify GPT.forward(idx, targets=None, position_ids=None) so the default path uses ordinary dense positions arange(T), while optional position_ids index the learned position embeddings. Train with standard next-token cross-entropy on dense positions every iteration. After warmup_iters, every scale_interval iterations, sample a scale from values such as 1.25, 1.5, and 2.0, build strictly increasing integer position_ids = floor(scale * arange(T)), and run a second forward pass on the same X and Y. Add a small ramped auxiliary loss on the scaled-position pass: scaled next-token cross-entropy plus a temperature-2.0 KL consistency term from detached dense-position logits to scaled-position logits, with total auxiliary weight up to 0.05 or 0.1. Extend get_batch(split, seq_len) and estimate_loss() to report validation loss at context lengths 128, 256, 384, and 512, including suffix-only loss on the final 256 positions for longer contexts. Compare the original 256-position baseline, a 512-position learned-position baseline without dilation, and position-scale consistency across shakespeare_char, enwik8, and text8. Report best 256-token validation loss, 384/512-token extrapolation loss, degradation from 256 to 512, dense-to-scaled prediction KL, total train time, and inference tokens per second. Generation remains unchanged except that the trained model can use the expanded positional table for longer contexts.
