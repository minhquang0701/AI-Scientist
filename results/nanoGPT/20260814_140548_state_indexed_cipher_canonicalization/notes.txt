# Title: State-Indexed Cipher Canonicalization for Causally Invariant Character Language Models
# Experiment description: Create a small fixed bank of reversible stateful ciphers over each dataset vocabulary. Each cipher has a few states, frequency-bucket-preserving vocabulary permutations per state, and a deterministic state update depending only on the visible raw token. Extend GPTConfig/GPT with optional view embeddings and cipher-state embeddings added to token and position embeddings; the default raw path is unchanged. Train every iteration with ordinary raw next-character cross-entropy. After warmup_iters, every cipher_interval iterations, reconstruct chunk = torch.cat([X[:, :1], Y], dim=1), encode it through a sampled cipher, compute the causal cipher state at each prediction position, and run a coded-view forward with view_id=1 and cipher_state_ids. Instead of predicting coded targets, map the coded-view hidden states through the ordinary tied lm_head to canonical raw-token logits and add a small ramped temperature-2 KL loss from detached raw-view logits to coded-view canonical logits, plus optional raw-target CE on the coded view. Evaluation and generation use only the raw path. Extend estimate_loss to report raw validation loss, coded-view canonical validation loss, raw-to-coded KL, validation loss under held-out ciphers, expected calibration error, train-val gap, total train time, and unchanged raw generation tokens per second. Compare the baseline, static permutation consistency, stateful cipher CE in coded-token space, state-indexed cipher canonicalization, and shuffled-state controls across shakespeare_char, enwik8, and text8.
