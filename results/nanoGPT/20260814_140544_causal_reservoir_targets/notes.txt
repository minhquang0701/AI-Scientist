# Title: Causal Reservoir Targets for Train-Only Memory Supervision in Character Transformers
# Experiment description: Modify GPT.forward() to optionally return final hidden states after ln_f. Add a small train-only reservoir_head Linear(n_embd, reservoir_dim), with reservoir_dim kept modest such as 64 or 128. After loading vocab_size, create fixed random token feature vectors and a frozen contractive causal reservoir with a few timescales, for example decays [0.5, 0.8, 0.95], updated as r_t = tanh(decay * signed_shift(r_{t-1}) + input_scale * feature[x_t]). Add compute_reservoir_targets(X) that scans each batch left to right using only visible input tokens and returns detached, normalized reservoir states for every position. Train with ordinary next-character cross-entropy on every iteration; after warmup_iters and every reservoir_interval iterations, run with return_hidden=True and add a small ramped cosine or Huber loss from reservoir_head(hidden) to the reservoir targets, with lambda_reservoir in the range 0.02 to 0.10. Evaluation and generation ignore the reservoir head and use only the standard lm_head, so inference cost is unchanged. Extend estimate_loss() to report ordinary train/validation loss, reservoir prediction error, validation loss at context lengths 64/128/256, repeated-target versus novel-target loss, train-val gap, total train time, and inference tokens per second. Compare against the baseline, shuffled-time reservoir targets, commutative prefix-count sketch supervision, and a detached-hidden probe control across shakespeare_char, enwik8, and text8.
