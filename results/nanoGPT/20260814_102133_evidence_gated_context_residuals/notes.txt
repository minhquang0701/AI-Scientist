# Title: Evidence-Gated Context Residuals for Single-Pass Long-Context Prediction
# Experiment description: Modify GPT.forward() to optionally return final hidden states after ln_f and to optionally add a context_residual_head(hidden) correction to the ordinary tied lm_head logits. Add context_residual_head = Linear(n_embd, vocab_size), initialized to zero, plus a learned scalar residual_gate initialized to zero so the enabled model starts exactly as the baseline. Train every iteration with ordinary full-context next-character cross-entropy from the base logits as the primary objective. After warmup_iters and every residual_interval iterations, run one additional short-context forward on X[:, -L:], Y[:, -L:] with L=64 as the default. Align the final L positions, compute detached full-context and short-context log probabilities, and form a centered residual target r = logp_full - logp_short. Compute detached evidence_gain = clamp(short_target_nll - full_target_nll, min=0), convert it to a bounded gate, and train the residual head with a gated Huber or MSE loss so only positions where full context helps strongly supervise the correction. Add a small ramped fused CE term on base_logits + residual_gate * centered_residual_pred while retaining the base CE anchor. Extend estimate_loss() to report base validation loss, fused validation loss, residual prediction error, mean evidence gain, validation loss at context lengths 64 and 256, repeated-target versus novel-target loss, previous-occurrence-distance buckets, learned residual gate, train-val gap, total train time, and base versus fused inference tokens per second. Compare the baseline, ungated residual prediction, post-hoc two-pass context-residual decoding, and evidence-gated amortized context residuals across shakespeare_char, enwik8, and text8.
