# Title: Prequential Attention Transport for Stable Autoregressive Context Tracking
# Experiment description: Modify CausalSelfAttention.forward, Block.forward, and GPT.forward to optionally return attention probabilities from selected layers, using the manual causal attention path only on sparse auxiliary iterations while preserving the default flash-attention path for ordinary training, evaluation, and generation. Train with standard next-character cross-entropy on every iteration. After warmup_iters, every transport_interval iterations, run the current batch with attention returns enabled for one late layer, or optionally layers 3 and 5. Compute observed-token surprisal for X[:, t] from detached logits at t - 1, since logits at t - 1 predict the next observed input token. Convert this surprisal into a detached gate that is high for unsurprising updates and low for surprising updates. For sampled query positions after a small burn-in, compare attention at query t over shared old keys <= t - 1 against attention at query t - 1 over those same keys, renormalizing both distributions and using bounded Jensen-Shannon divergence. Add a small ramped auxiliary loss lambda_transport * gate * JS, with lambda_transport values such as 0.001, 0.005, and 0.01. Extend estimate_loss to report ordinary train and validation loss as the primary metric, attention transport divergence, gated versus ungated divergence, validation loss by observed-surprisal bucket, train-val gap, total train time, and unchanged default generation tokens per second. Compare against the baseline, a manual-attention no-regularizer control, an ungated transport regularizer, and a shuffled-surprisal-gate control across shakespeare_char, enwik8, and text8.
