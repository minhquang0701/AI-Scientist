# Title: Surprisal-Event Prediction for Event-Aware Character Language Models
# Experiment description: Before training each dataset, scan train.bin to build a frozen smoothed backoff n-gram scorer using suffix lengths such as 1, 2, and 4, plus a unigram baseline. Define each token's event score as contextual excess surprisal, ngram_nll - unigram_nll[target], and choose a train-only percentile threshold such as the 80th percentile. Modify GPT.forward() to optionally return final hidden states after ln_f, and add two training-only auxiliary heads: an event_offset_head predicting buckets for the first future high-excess-surprisal event within H characters, such as 2-4, 5-8, 9-16, 17-32, or none, and an event_token_head predicting the token at that event position when one exists. On auxiliary iterations, sample block_size + H + 1 contiguous tokens, keep ordinary X and Y for standard next-character cross-entropy, compute event labels from the future part of the chunk, and add a small ramped auxiliary loss combining offset CE and event-token CE with lambda_event around 0.05 to 0.15. Evaluation and generation ignore the auxiliary heads and use the standard lm_head unchanged. Extend estimate_loss() to report ordinary train and validation loss as the primary metric, event offset accuracy, event-token accuracy, validation loss near high-surprisal events versus predictable regions, train-val gap, total train time, generation repetition diagnostics, and unchanged inference tokens per second. Compare against the baseline, fixed-horizon future-token auxiliary heads, boundary-forecast auxiliary supervision, and shuffled event-label controls across shakespeare_char, enwik8, and text8.
