# Title: Finite-Difference Block-Gain Regularization for Stable Autoregressive Transformers
# Experiment description: Modify GPT.forward to optionally return hidden states entering each transformer block, only on auxiliary iterations. Add a block_gain_penalty helper: after warmup_iters and every gain_interval steps, select one transformer block, detach its input hidden state, add a small RMS-normalized random perturbation, temporarily run that block with dropout disabled on both clean and perturbed inputs, and estimate local gain as ||Block(h + eps v) - Block(h)|| / (eps ||v||). Add a small ramped hinge penalty when log gain falls outside a conservative band such as log(0.8) to log(1.25). Keep ordinary next-character cross-entropy as the primary loss on every iteration. If torch.compile is enabled, keep an uncompiled model handle for accessing individual blocks while sharing parameters. Evaluation and generation use the unchanged default forward path. Log ordinary train and validation loss, estimated block gain by layer, train-val gap, gradient norm, total train time, and inference tokens per second. Compare against the baseline, a hidden-norm penalty control, and a compute-matched extra-block-forward control across shakespeare_char, enwik8, and text8.
