# Title: Markov-Regime Softmaxes for Nonstationary Character Language Modeling
# Experiment description: Extend GPTConfig with use_markov_regime_softmax, num_regimes, regime_rank, transition_diag_bias, and base_anchor_weight. In GPT.__init__, add K regime-specific low-rank output residuals, learned initial-regime logits, and a learned K by K transition-logit matrix. Initialize the residual factors so all regimes start identical to the ordinary tied-softmax baseline, and initialize transitions with a mild diagonal bias to favor persistent regimes. Modify GPT.forward to compute ordinary base logits, and when enabled also compute per-regime logits from base_logits plus the low-rank residuals. Add markov_regime_nll(logits_by_regime, targets, init_logits, transition_logits), using a log-space HMM forward algorithm over sequence positions; ignored targets contribute zero emission likelihood and the loss is normalized by valid target count. Train with the Markov-regime marginal NLL plus a small ordinary base-logit cross-entropy anchor. Extend estimate_loss to report base validation loss, Markov-marginal validation loss, static-mixture validation loss with transitions disabled, posterior regime entropy, expected switch rate, learned transition matrix, train-val gap, total train time, and base-path inference tokens per second. Add an optional generate_markov_filtered() diagnostic that maintains the causal posterior over regimes after each sampled token and samples from the filtered emission mixture. Compare baseline GPT, a single low-rank output-residual control, static regime mixtures, Markov-regime softmaxes, and shuffled-transition controls across shakespeare_char, enwik8, and text8.
