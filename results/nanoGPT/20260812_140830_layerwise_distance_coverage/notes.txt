# Title: Layerwise Distance-Coverage Regularization for Context-Using Character Transformers
# Experiment description: Modify CausalSelfAttention.forward, Block.forward, and GPT.forward to accept an optional distance_coverage flag. When disabled, keep the current flash-attention path unchanged. When enabled after warmup_iters every coverage_interval iterations, use the manual causal attention path, compute attention probabilities, and aggregate attention mass into coarse causal distance bands such as 0-1, 2-7, 8-31, 32-127, and 128-255. Ignore query positions where a distance band is unavailable. For each layer, average band mass across heads and add a small hinge loss that only penalizes collapse of medium and far context use, for example relu(mid_floor - mid_mass)^2 + relu(far_floor - far_mass)^2, with lambda_coverage ramped to a small value such as 0.001 to 0.01. Do not force every head to match the same profile; log per-head band usage only as diagnostics. Train with ordinary next-character cross-entropy as the primary objective, and keep evaluation and generation unchanged by default. Extend estimate_loss to report ordinary validation loss, validation losses at context lengths 32, 64, 128, and 256, attention mass by distance band, far-band usage by layer, and validation loss by previous-occurrence distance of the target character. Compare against the baseline, a manual-attention no-regularizer control, and a per-query attention-entropy floor control across shakespeare_char, enwik8, and text8. Report best validation loss, long-context robustness, repeated-token loss, train-val gap, total train time, and unchanged default generation tokens per second.
