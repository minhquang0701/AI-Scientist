# Title: Prefix Time-Warp Consistency for Alignment-Robust Character Language Modeling
# Experiment description: Keep the GPT architecture, ordinary next-token objective, evaluation path, and generation code unchanged by default. Add a helper that creates X_warp by leaving a recent suffix unchanged, such as the final 96 or 128 tokens, and replacing only the older prefix with a fixed-length monotone resampling of itself. The resampling uses a low edit rate: most source indices advance normally, while occasional stutter steps repeat the previous token and occasional skip steps jump ahead by one token, with indices clipped to remain valid and nondecreasing. In the training loop, always optimize the standard clean cross-entropy on X, Y. After warmup_iters, every warp_interval iterations, run a second forward pass on X_warp and add a ramped KL consistency loss between detached clean logits and warped logits only on the protected suffix, using temperature 2.0 and lambda_warp up to 0.05 or 0.1. Extend estimate_loss to report ordinary clean train/validation loss as the primary metric, suffix validation loss under fixed prefix warp rates, clean-to-warp degradation, consistency KL, total train time, and inference tokens per second. Compare against the baseline across shakespeare_char, enwik8, and text8, with small ablations over warp rate, protected suffix length, stutter-only warps, and skip-only warps.
