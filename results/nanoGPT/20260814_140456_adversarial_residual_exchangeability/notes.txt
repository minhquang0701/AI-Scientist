# Title: Adversarial Residual Exchangeability for Sequentially Calibrated Character Language Models
# Experiment description: Keep the GPT architecture, data loader, ordinary next-character cross-entropy objective, evaluation path, and generation code unchanged. After loading each dataset vocabulary, create a fixed normalized random projection matrix R from token ids to a residual sketch dimension such as 32. Add a small train-only ResidualOrderDiscriminator, implemented as a shallow Conv1d over residual-sketch sequences with no absolute-position inputs. On scheduled auxiliary iterations after warmup_iters, compute logits and probabilities, then form projected forecast residuals e_t = R[target_t] - probs_t @ R for valid targets. Standardize e_t by the detached model-implied projected variance to reduce trivial confidence-scale cues. Train the discriminator with its own small optimizer on detached residual sequences to distinguish true chronological order from within-sequence block-shuffled controls that preserve marginal and short-range residual statistics. Then freeze the discriminator and update GPT with ordinary CE plus a small ramped adversarial confusion loss through the non-detached residual sketches, using lambda_adv values such as 0.001, 0.005, and 0.01 every 4 or 8 iterations. Extend estimate_loss to report ordinary train/validation NLL, held-out residual-order discriminator AUC, residual autocorrelation by lag, expected calibration error, Brier score, validation loss by confidence bucket, train-val gap, total train time, and unchanged generation tokens per second. Compare against the CE baseline, fixed martingale residual whitening, discriminator-probe-only training with no GPT adversarial update, and shuffled-label discriminator controls across shakespeare_char, enwik8, and text8.
