# Title: Prequential Ridge Fast Heads for Prompt-Local Language Model Calibration
# Experiment description: Modify GPT.forward() to optionally return final hidden states after ln_f. After loading each dataset vocab_size, create fixed normalized random projection matrices R_vocab of shape vocab_size by sketch_dim and R_hidden of shape n_embd by fast_dim, with sketch_dim and fast_dim set to small values such as 32 or 64. During ordinary training, optimize the standard next-character cross-entropy unchanged. After warmup_iters, every fasthead_interval iterations, split each batch into an adaptation prefix and protected suffix. From a normal forward pass, compute detached prefix residual sketches e_t = R_vocab[target_t] - softmax(logits_t) @ R_vocab, fit a per-sequence ridge map W from projected prefix hidden features to these residual sketches using a small batched fast_dim by fast_dim solve, detach W, and apply it to projected suffix hidden features. Map predicted residual sketches back to vocabulary space with R_vocab.T and add a bounded scaled correction to suffix logits. Add a small ramped auxiliary suffix cross-entropy loss on the corrected logits, optionally with a weak KL anchor to the base logits. Extend estimate_loss to report ordinary validation loss as the primary metric, fasthead-corrected suffix validation loss, adaptation gain, expected calibration error, residual-sketch prediction error, shuffled-prefix-residual control loss, correction scale diagnostics, total train time, and unchanged base generation tokens per second. Default generation uses the base model unchanged, with an optional diagnostic that fits the fast head on the prompt prefix before sampling.
