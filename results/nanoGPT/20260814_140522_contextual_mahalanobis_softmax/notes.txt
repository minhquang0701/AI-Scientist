When enabled, compute ordinary base logits from the tied token embedding matrix, then project both final hidden states and token embeddings into a small shared metric subspace with rank 8 or 16. A metric_head predicts bounded nonnegative per-position weights over this subspace. Add a vocabulary-centered correction proportional to -0.5 * sum_r weight_r * (h_proj_r - token_proj_r)^2 to the base logits, multiplied by a learned scalar gate initialized to a tiny nonzero value such as 1e-3 so the model starts close to the baseline while metric parameters receive gradients. Train with next-character cross-entropy on the corrected logits plus a small base-logit CE anchor and optional metric-weight L2 after warmup. Modify generate() to use logits_from_hidden, and add diagnostics that evaluate the same model with the metric correction disabled. Compare the baseline, static learned Mahalanobis correction, contextual Mahalanobis ranks 8 and 16, adaptive-temperature control, and random-subspace control across shakespeare_char, enwik8, and text8. Report corrected validation loss, base-only validation loss, best validation loss, expected calibration error, rare versus common token loss, repeated versus novel target loss, learned gate value, metric weight entropy, correction magnitude, train-val gap, total train time, and inference tokens per second.
