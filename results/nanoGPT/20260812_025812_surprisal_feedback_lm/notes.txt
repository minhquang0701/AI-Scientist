# Title: Causal Surprisal Feedback for Prediction-Error-Aware Character Language Models
# Experiment description: Extend GPTConfig with use_surprisal_feedback, surprisal_gate_init, surprisal_clip, feedback_interval, and lambda_feedback_max. In GPT.__init__, add a Linear(1, n_embd) surprisal_proj and a learned scalar gate initialized near zero. Modify GPT.forward(idx, targets=None, surprisal_values=None) so the default path is unchanged, but when surprisal_values is provided it adds gate * surprisal_proj(surprisal_values.unsqueeze(-1)) to token embeddings before positional embeddings. In the training loop, always compute the ordinary clean next-token cross-entropy. After warmup_iters, every feedback_interval iterations, compute detached previous-token surprisal from the clean logits aligned to input positions: surprisal[:, 0] = 0 and surprisal[:, 1:] = -log p_clean(X[:, 1:] | X[:, :-1]). Clamp and normalize these values, run one feedback-conditioned second forward pass on the same X and Y, and optimize total_loss = clean_loss + lambda_feedback * feedback_loss with lambda_feedback ramped up to 0.25. Add one shuffled-surprisal control that permutes surprisal_values across batch elements before the second pass. Extend estimate_loss() to report clean train/validation loss, feedback-conditioned train/validation loss as the main augmented-model metric, validation loss binned by previous-token surprisal, clean-to-feedback KL, learned feedback gate value, total train time, and inference tokens per second. Optionally add generate_with_surprisal_feedback() that updates the scalar feedback after each generated token while keeping ordinary generate() unchanged. Compare baseline, true surprisal feedback, and shuffled-surprisal feedback across shakespeare_char, enwik8, and text8.
