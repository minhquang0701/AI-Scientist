# Title: Online Innovation Filters for Self-Correcting Character Language Models
# Experiment description: Extend GPT with an optional OnlineInnovationFilter applied after the normal tied lm_head. Add GPTConfig fields such as use_innovation_filter, innovation_dim, filter_hidden_dim, innovation_gate_init, and base_anchor_weight. Register a fixed normalized random projection R from vocab_size to innovation_dim. In GPT.forward, compute full base logits, then build leakage-free detached innovation sketches from already observed inputs: innovation[:, 0] = 0 and innovation[:, t] = R[idx[:, t]] - softmax(base_logits[:, t - 1]).detach() @ R for t > 0. Scan these innovations with a small GRU or diagonal recurrent filter, project the filter states back to innovation_dim, map them to vocabulary-logit residuals with R.T, center the residual over the vocabulary, and add gate * residual to the base logits. Initialize the gate to zero so the model starts exactly as the baseline. Train with fused-logit cross-entropy plus a small base-logit cross-entropy anchor, ramping the fused correction after warmup. Modify estimate_loss to report base validation loss, fused validation loss, expected calibration error, residual norm, gate value, loss by previous-token surprisal, repeated versus novel target loss, and local-frequency bucket loss. Compare against the baseline, zero-gate ablation, shuffled-innovation control, and fixed EMA residual filter control across shakespeare_char, enwik8, and text8. Generation can use the base path unchanged or a diagnostic fused path that recomputes the causal innovation filter from the visible context before sampling.
