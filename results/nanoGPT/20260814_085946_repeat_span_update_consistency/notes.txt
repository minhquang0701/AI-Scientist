# Title: Repeat-Span Update Consistency for Reusable Autoregressive Computation
# Experiment description: Modify GPT.forward() to optionally return final hidden states after ln_f while keeping the default evaluation and generation path unchanged. Add a find_repeated_spans(X, span_lengths=[4, 8, 16], max_pairs=256) helper that finds non-overlapping earlier/later exact substring matches within each sequence using simple rolling hashes or tuple dictionaries. Train every iteration with ordinary next-character cross-entropy. After warmup_iters and every repeat_interval iterations, run the normal forward pass with return_hidden=True, compute hidden update vectors h[:, 1:] - h[:, :-1], L2-normalize them, and sample repeated-span pairs. For each pair, add a small ramped cosine or InfoNCE loss that makes the later occurrence's update trajectory closer to the earlier occurrence than to same-length decoy spans from other batch positions. Gate or skip pairs whose detached predictive distributions over the matched spans have very high disagreement, so context-sensitive repetitions are not forced to collapse. Extend estimate_loss() to report ordinary validation loss as the primary metric, repeated-span versus non-repeated validation loss, update-trajectory retrieval accuracy, active repeated-span pair count, loss by previous-match distance, train-val gap, total train time, and unchanged generation tokens per second across shakespeare_char, enwik8, and text8. Compare against the baseline, shuffled-span-pair controls, and a same-compute auxiliary pass without the consistency loss.
