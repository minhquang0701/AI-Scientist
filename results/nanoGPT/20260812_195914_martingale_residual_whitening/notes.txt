# Title: Martingale Residual Whitening for Sequentially Calibrated Language Models
# Experiment description: Keep the GPT architecture, data loader, optimizer, evaluation path, and generation code unchanged. After loading each dataset's vocab_size, create a fixed random projection matrix R of shape vocab_size by sketch_dim, for example sketch_dim=32, with normalized rows. Add a martingale_residual_whitening_loss(logits, targets, R, lags=(1,2,4,8,16)) helper: compute probs = softmax(logits), form projected residuals e_t = R[target_t] - probs_t @ R for valid targets, and for each lag compute the batch-time cross-correlation matrix between current residuals e_t and detached past residuals e_{t-lag}. Center and variance-normalize the residual sketches over valid pairs, then penalize the mean squared entries of these lagged cross-correlation matrices. Train with ordinary next-character cross-entropy on every iteration; after warmup_iters, every whitening_interval iterations, add a small ramped lambda_white times this loss, sweeping lambda_white values such as 0.005, 0.01, and 0.05. Extend estimate_loss to report ordinary train and validation loss as the primary metric, residual autocorrelation by lag, expected calibration error, validation loss by predictive-entropy bucket, train-val gap, generated character-frequency KL, repeated-character rate, distinct n-gram fraction, total train time, and unchanged inference tokens per second. Compare against the baseline, a shuffled-lag residual control, uniform label smoothing, and local marginal calibration across shakespeare_char, enwik8, and text8.
