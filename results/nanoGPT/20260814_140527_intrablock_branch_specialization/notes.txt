# Title: Intra-Block Branch Specialization for Non-Redundant Transformer Computation
# Experiment description: Modify Block.forward to optionally return the attention residual update and the MLP residual update before they are added to the stream, and propagate a return_branch_updates flag through GPT.forward while keeping the default training, evaluation, and generation path unchanged. During ordinary iterations, train exactly as the baseline with next-character cross-entropy. After warmup_iters and every branch_interval iterations, run the normal forward pass with branch updates returned, subsample valid batch-time positions, and compute a conservative specialization penalty within each layer: L2-normalize attention and MLP update vectors, ignore positions where either update norm is below a detached percentile threshold, and penalize only excessive absolute cosine similarity with a hinge such as relu(abs(cosine) - margin)^2 using margins like 0.25 or 0.5. Ramp lambda_branch from 0 to small values such as 0.001, 0.005, and 0.01, while logging branch norms to detect collapse. Extend estimate_loss to report ordinary train and validation loss as the primary metric, attention-MLP cosine similarity by layer, branch norm ratios, and leave-one-branch-out validation degradation by temporarily zeroing either the attention or MLP update in one block at a time. Compare the baseline, branch specialization, a residual-norm penalty control, and a shuffled branch-pair control across shakespeare_char, enwik8, and text8. Generation remains unchanged, so any gains come from better training dynamics rather than extra inference compute.
