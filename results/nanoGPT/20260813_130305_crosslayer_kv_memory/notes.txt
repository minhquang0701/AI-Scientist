# Title: Gated Cross-Layer Key-Value Memory for Representation-Persistent Character Transformers
# Experiment description: Add an optional cross-layer memory path to GPT. Extend GPTConfig with use_crosslayer_kv_memory, memory_source_layer, memory_target_layers, memory_gate_init, memory_dropout, and detach_memory_source. Modify GPT.forward to store one early hidden stream, either the token-plus-position embedding stream or the output after block 1, and pass it only to selected upper Blocks such as the final two layers. Modify Block.forward and CausalSelfAttention.forward so target layers keep their normal causal self-attention, but also project the stored early stream into memory keys and values with a separate Linear layer. Reuse the current layer queries to attend causally over memory positions p <= t, concatenate the per-head memory outputs, and add them to the normal attention output through a learned scalar or per-head gate initialized to a tiny nonzero value such as 1e-3. Keep the data loader, optimizer, next-character cross-entropy objective, evaluation loop, and generation procedure unchanged. Compare the baseline, embedding-stream memory, block-1 memory, detached-memory ablation, and batch-shuffled-memory control across shakespeare_char, enwik8, and text8. Report ordinary train and validation loss, best validation loss, repeated-target versus novel-target loss, rare-token loss, validation loss at context lengths 64 and 256, learned memory gate values, memory attention distance profiles, parameter overhead, total train time, and inference tokens per second.
