# Title: Prequential SNML Regularization for Online-Learnability-Aware Character Language Models
# Experiment description: Modify GPT.forward() to optionally return final hidden states after ln_f. Add a local_snml_targets(logits, hidden, eta, correction_clip) helper that computes detached soft targets from a closed-form one-step output-layer virtual update, without perturbing model weights. For each batch-time position, compute p = softmax(logits), a = clip(eta * ||h||^2 / n_embd, max=correction_clip), and b = logits - a * p. For candidate token y, its virtual self-fitted score is b_y + a - log(exp(logsumexp(b)) + exp(b_y) * (exp(a) - 1)); normalizing these scores across y gives q_snml. Train every iteration with ordinary next-character cross-entropy; after warmup_iters and every snml_interval iterations, add a small ramped auxiliary soft cross-entropy from q_snml.detach() to log_softmax(logits), with lambda_snml values such as 0.02, 0.05, and 0.1. Evaluation and generation use ordinary logits unchanged. Extend estimate_loss to report ordinary validation NLL as the primary metric, SNML-target KL, optional post-hoc SNML-corrected validation NLL, expected calibration error, Brier score, rare-token loss, train-val gap, and correction magnitude. Compare the baseline, uniform label smoothing, post-hoc SNML correction only, train-time SNML regularization, hidden-norm-only smoothing, and shuffled-SNML-target controls across shakespeare_char, enwik8, and text8.
