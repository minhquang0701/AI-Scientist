# Title: Counterfactual Span Attention Alignment for Causal Context Use
# Experiment description: Modify CausalSelfAttention.forward, Block.forward, and GPT.forward to optionally return attention probabilities on auxiliary iterations, using the manual attention path only when attention maps are requested and leaving the default flash-attention path unchanged. Train with ordinary next-character cross-entropy on every iteration. After warmup_iters, every align_interval iterations, divide each input window into coarse prefix spans such as 16-token chunks and reserve a protected suffix such as the final 64 tokens as query positions. Under torch.no_grad(), create a small batched set of counterfactual copies where one candidate prefix span at a time is corrupted by same-batch token replacement or unigram-sampled replacement, rerun the model, and measure each span's influence as the increase in suffix target cross-entropy relative to the clean logits. Normalize positive influence scores into a span-level target distribution. On a trainable forward pass with returned attention maps, aggregate attention from protected suffix queries to each prefix span over selected late layers and heads, then add a small ramped KL or ranking loss aligning attention mass to the counterfactual influence distribution. Keep evaluation and generation unchanged. Extend diagnostics to report ordinary train/validation loss, attention-influence rank correlation, suffix validation loss, validation loss by previous-occurrence distance, train-val gap, total train time, and inference tokens per second. Compare against the baseline, a shuffled-influence control, and a uniform span-attention regularization control across shakespeare_char, enwik8, and text8.
