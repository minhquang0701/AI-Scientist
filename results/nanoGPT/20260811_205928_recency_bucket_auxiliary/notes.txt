# Title: Recency-Bucket Auxiliary Prediction for Reuse-Aware Language Modeling
# Experiment description: Modify GPT.forward() to optionally return final hidden states after ln_f. Add a small auxiliary classifier from hidden states to coarse logarithmic recency buckets for the next target token. For each position t, derive the label by finding the most recent visible prefix position p <= t where X[:, p] == Y[:, t], using buckets such as no previous occurrence, distance 1-4, 5-16, 17-64, and 65-255. Keep the ordinary next-token cross-entropy as the primary objective. After warmup_iters, every recency_interval iterations such as 4 or 8, compute recency labels for the current batch and optimize total_loss = lm_loss + lambda_recency * recency_loss, with class-balanced recency loss and lambda_recency ramped from 0.0 to 0.05 or 0.1. Evaluation and generation use only the standard lm_head, so inference behavior is unchanged. Extend estimate_loss() to report ordinary train/validation loss, macro recency-bucket accuracy, validation loss by recency bucket, and loss on novel versus repeated targets. Compare against the baseline and a shuffled-label auxiliary control across shakespeare_char, enwik8, and text8 using best ordinary validation loss, repeated-target validation loss, convergence speed, total train time, and unchanged inference tokens per second.
