# Title: Context-Support Confidence Caps for Memorization-Resistant Character Language Modeling
# Experiment description: Before training each dataset, scan train.bin once to build approximate Count-Min Sketch counts for fixed-length causal suffix contexts, using length 16 as the main setting and length 8 as a small ablation. Add a helper that computes rolling hashes for each batch X and returns a low-support mask for supervised positions whose visible suffix context has estimated train support below a threshold such as 2 or 4; positions with insufficient left context are left unregularized. Keep the GPT architecture, optimizer, batching, evaluation path, and generation code unchanged. In the training loop, always optimize ordinary next-character cross-entropy as the primary loss. After warmup_iters, compute per-token log probability of the true target from log_softmax(logits), and add a small ramped auxiliary penalty only on low-support contexts when the model becomes too confident, for example mean(mask * relu(log_p_target - log(p_cap))^2), with p_cap values such as 0.85, 0.90, and 0.95 and lambda_cap values such as 0.01 to 0.1. Extend estimate_loss to report ordinary train and validation loss, validation loss by context-support bucket, mean target confidence by support bucket, train-val gap on low-support contexts, and a simple train-versus-validation window-loss membership diagnostic. Compare against the baseline, uniform label smoothing, rarity-balanced CE, and a random-support-mask control across shakespeare_char, enwik8, and text8. Generation remains unchanged, so inference tokens per second should be unaffected.
