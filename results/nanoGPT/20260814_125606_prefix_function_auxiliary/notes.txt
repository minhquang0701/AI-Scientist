# Title: Prefix-Function Auxiliary Supervision for Algorithmic String Memory
# Experiment description: Modify GPT.forward() to optionally return final hidden states after ln_f. Add small training-only auxiliary heads that predict bucketed prefix-function features from each hidden state. Add compute_prefix_function_targets(X, window=128), which for each position t takes the causal recent string X[:, max(0, t - window + 1):t + 1] and computes three labels from its KMP prefix-function: longest proper border length, fallback-chain depth, and approximate period length. Log-bucket the labels and mask very short contexts. Train with ordinary next-character cross-entropy on every iteration. After warmup_iters and every prefix_interval iterations, run the normal forward pass with return_hidden=True and add a small ramped auxiliary loss for the prefix-function labels, keeping the language-model CE dominant. Evaluation and generation use only the standard lm_head. Extend estimate_loss() to report ordinary train and validation loss as the primary metric, auxiliary prediction accuracy, validation loss by border and period bucket, repeated-substring versus non-repeated loss, train-val gap, total train time, and unchanged inference tokens per second. Compare against the baseline, border-only auxiliary, shuffled-label controls, and a parameter-matched auxiliary-head control across shakespeare_char, enwik8, and text8.
