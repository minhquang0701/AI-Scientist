# Title: Source-Indexed Prefix Warp Consistency for Rate-Robust Character Language Modeling
# Experiment description: Keep the GPT architecture, ordinary next-character cross-entropy objective, evaluation path, and generation code unchanged. Add get_warp_pair_batch(split), which samples longer memmap chunks and constructs two block_size-length views: a clean contiguous view and a warped view whose older prefix is generated by a monotone source-index map with low-rate skips and duplicates. Preserve a recent source suffix of roughly 96 or 128 characters, but allow that same suffix to appear at shifted absolute positions in the two views by using small bounded prefix-length differences. Return X_clean, Y_clean, X_warp, Y_warp, and source-index maps for the prediction targets. Train ordinary clean CE every iteration. After warmup_iters, every warp_interval iterations, run both views, gather logits whose target source indices match inside the protected suffix, and add a small ramped temperature-2 KL consistency loss from detached clean logits to warped logits, optionally plus warped-view CE with a conservative weight. Extend estimate_loss() to report ordinary validation loss, warped-prefix validation loss, source-aligned suffix KL, clean-to-warp degradation, loss by distance into the aligned suffix, train-val gap, total train time, and unchanged generation tokens per second. Compare against the baseline, same-position prefix edit consistency, random prefix masking, and a shuffled-source-alignment control across shakespeare_char, enwik8, and text8.
