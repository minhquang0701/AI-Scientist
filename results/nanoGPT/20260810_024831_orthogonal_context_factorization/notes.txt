# Title: Orthogonal Context Factorization for Robust Character Language Modeling
# Experiment description: Extend GPTConfig with use_context_factorization, context_factor_dim, context_factor_loss_weight, context_orth_weight, and context_factor_ramp_iters. In GPT.__init__, add an identity-initialized predictive_adapter mapping n_embd to n_embd, a context_proj mapping n_embd to context_factor_dim, and two small auxiliary heads from the context stream: one predicts a coarse absolute position bucket and one predicts the previous-occurrence distance bucket of the current input token, both computed causally from idx only. In GPT.forward, after ln_f compute h_pred = predictive_adapter(hidden) and h_ctx = context_proj(hidden). Use h_pred with the existing tied lm_head for the ordinary next-character logits, validation, and generation. During training, add the two context-descriptor cross-entropy losses from h_ctx plus an orthogonality penalty equal to the squared cross-covariance between centered sampled h_pred and h_ctx activations. Train with total_loss = next_token_loss + alpha_t * context_loss + beta_t * orthogonality_loss, ramping alpha_t and beta_t after warmup_iters. Keep estimate_loss, final reporting, inference speed, and generated samples based on ordinary next-character loss. Add diagnostics for clean validation loss, cropped-context validation at 64 and 128 tokens, context-head accuracies, predictive-stream position leakage via a lightweight probe, cross-covariance magnitude, calibration, parameter overhead, and adapter deviation from identity. Compare the baseline against context_factor_dim values 64 and 128 with context_factor_loss_weight values 0.02 and 0.05, plus ablations with context heads but no orthogonality and orthogonality with only the position-bucket head across shakespeare_char, enwik8, and text8.
