# Title: Edit-Recovery Consistency for Robust Autoregressive State Formation
# Experiment description: Keep the GPT architecture, ordinary next-character cross-entropy objective, evaluation path, and generation code unchanged. Add a helper that constructs an edited-prefix view of each batch by preserving the final suffix of length S, such as 96 or 128 tokens, exactly at the same positions, while applying low-rate fixed-length edit surrogates only to the older prefix: adjacent swaps, local duplications compensated by nearby deletions, and local deletions compensated by nearby repeats. In the training loop, always optimize the clean next-token cross-entropy. After warmup_iters, every edit_interval iterations, run one additional forward pass on the edited-prefix batch and add a small ramped temperature-2 KL consistency loss from detached clean logits to edited-view logits only on the preserved suffix after a burn-in of 16 or 32 tokens. Extend estimate_loss() to report ordinary clean train/validation loss, validation loss under fixed prefix edit noise, clean-to-edited degradation, suffix KL, an edit-recovery curve showing loss by distance into the preserved suffix, train-val gap, total train time, and unchanged generation tokens per second. Compare against the baseline, random prefix masking with the same corruption rate, prefix replacement consistency, and edited-prefix training without the KL term across shakespeare_char, enwik8, and text8.
