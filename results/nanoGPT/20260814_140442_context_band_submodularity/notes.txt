# Title: Context-Band Submodularity for Non-Interfering Long-Context Language Modeling
# Experiment description: Add an optional learned mask_embedding to GPT and modify GPT.forward(idx, targets=None, input_mask=None) so masked input positions replace token embeddings before positional embeddings; the default path remains unchanged. In train(), always optimize ordinary clean full-context next-character cross-entropy. After warmup_iters, every submod_interval iterations, protect a recent suffix such as the final 64 or 96 tokens and partition the older prefix into two contiguous distance bands A and B. Reuse the clean logits as the full S+A+B view, where S is the protected recent suffix context. Run three additional masked forward passes on the same X,Y: S only, S+A, and S+B. Compute unreduced target NLL only on protected suffix positions. Add safe monotonicity penalties such as relu(nll_SA - nll_S.detach() - margin), relu(nll_SB - nll_S.detach() - margin), relu(nll_full - nll_SA.detach() - margin), and relu(nll_full - nll_SB.detach() - margin), so richer contexts are trained not to underperform poorer contexts. Add a stop-gradient submodularity penalty that reduces excessive context synergy without encouraging clean degradation, for example relu((nll_SB + nll_SA) - (nll_full.detach() + nll_S.detach()) - margin), optionally downweighted for very high-entropy clean predictions. Keep clean CE dominant and leave generation unchanged. Extend estimate_loss to report ordinary validation loss, fixed-band masked validation losses, negative context-gain rate, submodularity violation rate, repeated versus novel target loss, train-val gap, total train time, and unchanged generation tokens per second. Compare against the baseline, random band masking, clean-to-masked band distillation, and short-vs-full monotonicity across shakespeare_char, enwik8, and text8.
