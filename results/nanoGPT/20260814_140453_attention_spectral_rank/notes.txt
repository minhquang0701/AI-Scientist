# Title: Nonlocal Attention Spectral Rank Regularization for Context-Rich Character Transformers
# Experiment description: Modify CausalSelfAttention.forward, Block.forward, and GPT.forward to optionally return attention probabilities from selected layers, using the manual causal attention path only on scheduled auxiliary iterations while preserving the default flash-attention path for ordinary training, evaluation, and generation. Add attention_spectral_rank_loss(attn_maps, local_window=16, num_queries=64, min_nonlocal_mass=0.05, target_rank=4) that samples one or two layers, a small subbatch, and query positions with enough visible history. For each sampled head, exclude each query's recent local window, renormalize nonlocal attention rows only when sufficient nonlocal mass is present, L2-normalize the sampled rows, and compute a cheap participation-ratio effective rank from the row Gram matrix rather than a full SVD. Add a small ramped hinge penalty only when effective rank falls below target_rank, while ordinary next-character cross-entropy remains dominant. Extend diagnostics to report ordinary train/validation loss, nonlocal attention mass, effective rank by layer/head, attention sink concentration, validation loss at context lengths 64/128/256, repeated-target versus novel-target loss, and previous-occurrence-distance loss buckets. Compare against the baseline, a manual-attention no-regularizer control, rowwise attention-entropy regularization, and attention head-diversity regularization across shakespeare_char, enwik8, and text8. Generation remains unchanged.
