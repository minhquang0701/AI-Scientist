# Title: Spectral Prefix-Influence Regularization for Smooth Long-Context Use
# Experiment description: Modify GPT.forward to accept an optional embedding_delta tensor added after token embedding lookup and before positional embeddings, leaving the default path unchanged. Add a helper that samples a random embedding perturbation on only the older prefix while protecting a recent suffix such as the final 96 or 128 tokens, decomposes it into a smoothed low-frequency component using causal or centered temporal average pooling and a high-frequency residual component, and RMS-matches both components to a fixed epsilon. In train(), always compute ordinary next-character cross-entropy and clean logits. After warmup_iters, every spectral_interval iterations, run a no-grad low-frequency perturbed forward and a trainable high-frequency perturbed forward on the same batch. Compute temperature-scaled KL from detached clean suffix logits to each perturbed suffix prediction, then add a small ramped hinge penalty relu(KL_high - KL_low.detach() - margin), keeping CE dominant. Evaluation and generation use the clean path unchanged. Extend estimate_loss to report ordinary validation loss, low- and high-frequency prefix perturbation KL, high-to-low influence ratio, validation loss under fixed spectral perturbations, train-val gap, total train time, and clean generation tokens per second. Compare against the baseline, matched isotropic prefix-noise consistency, prefix VAT smoothing, and a low-frequency-penalized control across shakespeare_char, enwik8, and text8.
