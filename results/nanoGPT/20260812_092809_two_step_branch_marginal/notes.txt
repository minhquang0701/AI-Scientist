# Title: Two-Step Branch Marginalization for Autoregressive Rollout Calibration
# Experiment description: Keep the GPT architecture, data loader, optimizer, ordinary next-character cross-entropy, evaluation path, and default generation unchanged. Add a helper two_step_branch_marginal_loss(model, X, Y, logits, top_k=4) that uses the penultimate input position in each sequence as an anchor. From detached logits[:, -2, :], take the top-k next-token candidates and their log probabilities. Repeat X top-k times, replace the final input token with each candidate, run one batched branched forward pass, and read the final-position log probability of the true final target Y[:, -1]. Compute the two-step marginal negative log likelihood using logsumexp(log p(c | prefix) + log p(Y_final | prefix, c)) over the top-k branches, treating this as a lower bound on the true two-step probability. After warmup_iters, every branch_interval iterations such as 8, optimize loss = ordinary_ce + lambda_branch * branch_marginal_nll, ramping lambda_branch to 0.05 or 0.1. Include small ablations with non-detached first-step probabilities and top-k-renormalized branch probabilities. Extend estimate_loss to report ordinary train and validation loss as the primary metric, two-step branch marginal NLL, top-k next-token coverage, train-val gap, rollout calibration error on validation batches, total train time, and unchanged one-step generation tokens per second. Compare against the baseline and a compute-matched extra-forward control that performs the branched pass but omits the marginal loss.
