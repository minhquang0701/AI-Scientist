# Title: Capped Causal De Bruijn State Lifting for Character Language Modeling
# Experiment description: Before training each dataset, scan train.bin to build a capped suffix-state vocabulary from train data. Include all single-character states, then add the most frequent observed bigram and trigram suffix states up to a fixed cap such as 4096 or 8192 total states; unseen suffixes back off to the longest available suffix, always ending in the current character. Modify GPTConfig and GPT to support separate input_vocab_size and output_vocab_size: transformer.wte embeds suffix-state ids, while lm_head predicts ordinary next-character ids. Modify get_batch() to sample raw block_size + 1 character chunks, convert each input position to its causal suffix-state id using only characters up to that position, and keep Y as raw next-character targets. Modify generation to maintain raw generated characters, convert the visible raw context to suffix-state ids before each forward pass, sample a raw next character, and update the context. Compare the original tied character baseline, an untied-output character baseline, capped bigram/trigram state lifting, and a within-current-character shuffled-state control that preserves state counts but breaks suffix semantics. Report character-level validation loss, convergence speed, parameter count, loss by state support and backoff depth, repeated versus novel target loss, train-val gap, total train time, and generated-character tokens per second across shakespeare_char, enwik8, and text8.
