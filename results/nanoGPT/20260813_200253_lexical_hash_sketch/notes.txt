# Title: Open-Vocabulary Lexical Hash Sketch Supervision for Character Language Models
# Experiment description: Derive separator token ids from each dataset meta.pkl using robust characters such as space, newline, tab, and common punctuation when present. Modify GPT.forward() to optionally return final hidden states after ln_f, and add a small training-only lexical_hash_head Linear(n_embd, num_hashes * num_buckets), with defaults such as num_hashes=4 and num_buckets=256. Add compute_lexical_hash_targets(X, Y, num_hashes, num_buckets, max_segment_len=32), reconstructing chunks as torch.cat([X[:, :1], Y], dim=1), finding separator-delimited segments, masking separator targets, edge-truncated segments, and long segments, then assigning fixed salted rolling-hash labels to the full segment containing each valid next-character target. Train with ordinary next-character cross-entropy on every iteration; after warmup_iters and every lexical_interval iterations, add a ramped auxiliary cross-entropy over the valid hash heads with lambda_lexical around 0.05 to 0.15. Evaluation and generation ignore the lexical head and use the standard lm_head unchanged. Extend estimate_loss() to report ordinary train and validation loss as the primary metric, lexical hash accuracy, validation loss inside segments versus at separators, train-val gap, total train time, and unchanged inference tokens per second. Compare against the baseline, shuffled hash labels, separator-boundary-only auxiliary supervision, and a frequent-span classifier control across shakespeare_char, enwik8, and text8.
