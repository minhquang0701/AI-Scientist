# Title: Uncertainty-Gated Head Coverage for Belief-Aware Context Use
# Experiment description: Modify CausalSelfAttention.forward, Block.forward, and GPT.forward to optionally return attention probabilities on scheduled auxiliary iterations, using the manual attention path only when attention maps are requested and preserving the default flash-attention path otherwise. Train with ordinary next-character cross-entropy on every iteration. After warmup_iters and every coverage_interval iterations, run the current batch with attention maps enabled, compute detached normalized predictive entropy from the model logits, and aggregate attention maps from selected middle and late layers. For high-uncertainty query positions only, encourage the head-averaged attention distribution to have sufficient normalized causal entropy, while leaving individual heads unconstrained so sharp specialized heads remain possible. Use a small ramped one-sided hinge loss with a conservative entropy floor derived from predictive entropy, and ignore early positions with too few visible keys. Extend estimate_loss to report ordinary validation loss, expected calibration error, head-averaged attention entropy by predictive-entropy bucket, validation losses at context lengths 32, 64, 128, and 256, and train-val gap. Compare against the baseline, a manual-attention no-regularizer control, a fixed head-coverage floor, a per-head entropy-floor control, and a shuffled-predictive-entropy control across shakespeare_char, enwik8, and text8. Generation remains unchanged and uses the ordinary fast path.
