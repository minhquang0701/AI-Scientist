# Title: Prequential Automata Path Calibration for Sequence-Aware Character Language Models
# Experiment description: Keep the GPT architecture, optimizer, data loader, evaluation path, and generation code unchanged. After loading each dataset vocabulary, create a small train bank and a disjoint held-out diagnostic bank of random deterministic finite-state automata with 4-8 states over frequency-balanced binary or ternary token partitions. Add prequential_automata_path_loss(logits, X, Y, automata, window_len), which subsamples short windows, computes the actual automaton state at each window start from the visible prefix, propagates a predicted state distribution through the window using the model's teacher-forced next-token probabilities, and compares the predicted final state distribution with the realized final state reached by the target tokens using Brier or cross-entropy loss. Train every iteration with ordinary next-character cross-entropy; after warmup_iters and every automata_interval iterations, add a small ramped lambda_automata term for window lengths such as 8 and 16. Extend estimate_loss to report ordinary train and validation NLL as the primary metric, train-bank and held-out-bank automata path calibration error, generated-sample automata state-frequency error, expected calibration error, repeated n-gram rate, distinct n-gram fraction, train-val gap, total train time, and unchanged inference tokens per second. Compare against CE-only training, local marginal calibration, one-step DFA calibration, shuffled-automata controls, and shuffled-time target controls across shakespeare_char, enwik8, and text8.
