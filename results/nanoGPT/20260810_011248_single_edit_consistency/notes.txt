# Title: Single-Edit Consistency for Alignment-Robust Autoregressive Language Models
# Experiment description: Keep the GPT architecture, clean next-character objective, validation, and generation unchanged. Add a helper make_single_edit_batch(X, vocab_size, edit_prob, edit_prefix_len) that, independently for each example, either leaves the sequence unchanged or applies one random insertion or deletion inside the first edit_prefix_len tokens. The helper crops or pads back to block_size and returns X_edit, an alignment map where each edited timestep points to the clean timestep with the same current token, and a validity mask. In the training loop, compute the standard clean forward pass on X,Y and optimize ordinary cross-entropy as the primary loss. After warmup_iters, ramp edit_prob and alpha_t over 1000 iterations, run a second forward pass on X_edit, gather detached clean logits using the alignment map, and add temperature-scaled KL consistency only on valid aligned positions after edit_prefix_len + burn_in. Use edit_prefix_len=128, burn_in=16, temperature=2.0, alpha=0.05 as the main setting, with alpha=0.1 and max edit_prob values 0.02 and 0.05 as small ablations. Keep estimate_loss and final reporting based on clean validation loss for comparability. Add validation probes that apply insertion-only, deletion-only, and mixed single edits to validation batches, reporting aligned suffix cross-entropy, clean-to-edited KL, and robustness gap. Compare against the baseline across shakespeare_char, enwik8, and text8 using clean best validation loss, edit-corrupted validation loss, convergence speed, total train time, inference tokens per second, generated samples, and insertion-versus-deletion sensitivity.
