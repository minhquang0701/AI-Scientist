# Title: Contextual Prefix-Code Residual Modeling for Character Language Models
# Experiment description: Before training each dataset, scan train.bin to build a frozen smoothed causal prior over characters, using unigram plus shallow backoff suffix counts of length 1 and 2. Add a deterministic base-4 Shannon-Fano-style prefix coder that, given the currently decoded context and the frozen prior, recursively partitions the vocabulary into four nearly equal prior-mass groups and emits the code digits for the next character. Precompute or stream-encode train.bin and val.bin into valid code-symbol sequences with vocab_size=4, plus a validity mask for partial codewords during evaluation and generation. Train the existing GPT architecture unchanged on next-code-symbol cross-entropy, masking invalid code digits when inside a partial codeword. Report code-symbol NLL, exact character-normalized NLL from the lossless code path, prior-only codelength from a uniform code-symbol model, average code symbols per character, effective decoded context length, train time, and decoded-character generation speed. Compare raw character GPT, static Huffman or frequency prefix-code controls, contextual prefix-code GPT, and shuffled-prior contextual-code controls across shakespeare_char, enwik8, and text8, using character-normalized validation NLL as the primary metric.
