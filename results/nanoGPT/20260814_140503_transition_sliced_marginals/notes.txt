# Title: Transition-Sliced Marginal Calibration for Character Language Models
# Experiment description: Before training each dataset, scan train.bin once to compute smoothed predecessor distributions, successor distributions, and token frequencies for every character. Concatenate these transition fingerprints, normalize them, reduce them with deterministic SVD to a small embedding dimension such as 8 or 16, and precompute several fixed projection directions with their induced token orderings. Keep the GPT architecture, optimizer, data loader, ordinary next-character cross-entropy, evaluation, and generation unchanged. Add transition_sliced_marginal_loss(logits, targets, token_orders, chunk_len=64): split each sequence into non-overlapping chunks, average softmax probabilities over valid positions to get predicted local token marginals, build smoothed empirical target histograms for the same chunks, and penalize squared cumulative-distribution gaps along each transition-derived token ordering. Train with ordinary CE every iteration; after warmup_iters and every sliced_interval iterations, add a ramped lambda_sliced times this auxiliary loss with conservative values such as 0.005, 0.01, and 0.05. Extend estimate_loss to report ordinary train and validation NLL as the primary metric, transition-sliced marginal error, geometry-free local marginal JS error, expected calibration error, rare-token loss, generated character-frequency KL, repeated n-gram rate, distinct n-gram fraction, train-val gap, total train time, and unchanged inference tokens per second. Compare CE-only, local marginal JS calibration, transition-kernel scoring, random-token-order sliced controls, and shuffled-target-histogram controls across shakespeare_char, enwik8, and text8.
