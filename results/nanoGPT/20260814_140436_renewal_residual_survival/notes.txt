# Title: Renewal-Residual Survival Supervision for Reuse-Aware Character Language Models
# Experiment description: Before training each dataset, scan train.bin once to estimate fixed per-token self-return probabilities for horizons such as 4, 16, 64, and 128 characters, then convert them to clipped baseline logits. Modify GPT.forward() to optionally return final hidden states after ln_f, and add a small training-only return_residual_head Linear(n_embd, num_return_horizons). On auxiliary iterations, have get_batch() sample block_size + max_return_horizon + 1 contiguous tokens while still returning ordinary X and Y for next-character language modeling. Add compute_self_return_labels(chunk, horizons) that creates binary labels indicating whether the current input token appears again within each future horizon. Train every iteration with ordinary next-token cross-entropy; after warmup_iters and every return_interval iterations, add a ramped BCEWithLogits loss using baseline_return_logits[X] + return_residual_head(hidden_states), with lambda_return around 0.05 to 0.15. Evaluation and generation ignore the return head and use the standard lm_head unchanged. Extend estimate_loss() to report ordinary train/validation loss as the primary metric, return AUROC by horizon, residual gain over the fixed renewal baseline, validation loss by return-horizon bucket, repeated-target versus novel-target loss, previous-occurrence-distance loss, train-val gap, total train time, and unchanged inference tokens per second. Compare against the baseline, raw self-return auxiliary without renewal baselines, shuffled return-label controls, and the fixed renewal baseline predictor across shakespeare_char, enwik8, and text8.
