# Title: Retrodictive Posterior Distillation for Causal Character Language Models
# Experiment description: Keep the GPT architecture, ordinary next-character cross-entropy objective, evaluation path, and generation code unchanged. After warmup_iters and every posterior_interval iterations such as 8 or 16, choose one shared anchor position with room for a short future horizon H, for example 8 or 16 tokens. From detached clean logits at the anchor, take the top_k candidate next characters per sequence, with top_k around 4 or 8, and always include the gold next character. Repeat the batch over candidates, replace only X[:, anchor + 1] with each candidate, keep later teacher-forced inputs unchanged, and run one no-grad branched forward pass, chunked if needed for memory. Score only the subsequent observed continuation from positions anchor + 1 through anchor + H, excluding the anchor target itself, length-normalize this future log likelihood, and form a detached candidate posterior proportional to the clean anchor log probability plus beta times the future-evidence score. Add a small ramped auxiliary KL loss from this retrodictive posterior to the clean anchor logits restricted to the same candidate set, while retaining ordinary full-window CE as the dominant loss. Extend estimate_loss to report ordinary validation loss as the primary metric plus gold posterior mass, posterior entropy, anchor accuracy, expected calibration error, and validation loss by posterior-entropy bucket. Compare CE-only training, retrodictive posterior distillation, a compute-matched extra-forward control, a gold-only anchor CE control, and a shuffled-future-evidence control across shakespeare_char, enwik8, and text8. Default generation remains unchanged, so inference tokens per second should be unaffected.
