# Title: Context-Band Distillation for Robust Autoregressive Context Use
# Experiment description: Add a learned mask_embedding to GPT and modify GPT.forward(idx, targets=None, input_mask=None) so positions marked by input_mask replace their token embeddings with mask_embedding before positional embeddings; when input_mask is None, evaluation and generation are unchanged. In train(), always compute the standard clean full-context next-token cross-entropy. After warmup_iters, every band_interval iterations, sample one structured context-band mask for the same X: keep a protected recent suffix such as the final 96 or 128 tokens visible, divide the older prefix into coarse distance bands, and mask one band or an alternating set of old-prefix stripes. Run one masked-view forward pass and add a small ramped temperature-2 KL loss from detached clean logits to masked-view logits only on the protected suffix, with lambda_band up to 0.05 or 0.1. Extend estimate_loss() to report ordinary clean train/validation loss as the primary metric, validation loss under fixed far-band, middle-band, and striped-prefix masks, clean-to-masked degradation, and suffix KL. Compare against the baseline, random input masking at the same mask rate, and recent-only short-context distillation across shakespeare_char, enwik8, and text8 using best clean validation loss, masked-context robustness, train-val gap, total train time, and unchanged generation tokens per second.
