# Title: Transition-Kernel Proper Scoring for Calibrated Character Language Models
# Experiment description: Before training each dataset, scan train.bin once to compute smoothed predecessor and successor distributions for every token. Concatenate these distributions with normalized log frequency to form transition fingerprints, L2-normalize them, and build a positive-definite token kernel using an RBF kernel mixed with an identity kernel, for example K = (1 - rho) * I + rho * K_transition with rho in {0.25, 0.5, 0.75}. Normalize the kernel diagonal to 1 so the loss scale is comparable across datasets. Add a kernel_score_loss(logits, targets, kernel) helper that computes the finite-space kernel proper score p^T K p - 2 K[y]^T p + K[y,y] for valid target positions, where p = softmax(logits). In the training loop, keep ordinary next-character cross-entropy as the primary loss. After warmup_iters, every kernel_interval iterations such as 4, add a ramped lambda_kernel times the kernel score with conservative values such as 0.02, 0.05, and 0.1. Keep the GPT architecture, optimizer, data loader, evaluation path, and generation code unchanged. Extend estimate_loss to report ordinary train and validation NLL as the primary metric, kernel score, expected calibration error, Brier score, rare-token validation loss, generated character-frequency KL, total train time, and inference tokens per second. Compare against the baseline, uniform label smoothing, identity-kernel Brier regularization, transition-kernel scoring, and a shuffled-transition-kernel control across shakespeare_char, enwik8, and text8.
