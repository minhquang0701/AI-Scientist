# Title: Causal Residual Orthogonality for Conditionally Calibrated Language Models
# Experiment description: Keep the GPT architecture, data loader, optimizer, evaluation path, and generation code unchanged. After loading each dataset vocab_size, create two fixed normalized random feature tables: R_out mapping token ids to an output residual sketch dimension such as 16 or 32, and R_ctx mapping token ids to a context sketch dimension such as 16 or 32. Add build_causal_count_sketches(X, R_ctx, windows), which uses only visible input tokens up to each position to compute recent-window average context sketches for windows such as 16, 64, and 256, concatenated with a small absolute-position bucket feature. Add causal_residual_orthogonality_loss(logits, targets, context_sketches, R_out), which subsamples valid batch-time positions, computes probs = softmax(logits), projected forecast residuals R_out[target] - probs @ R_out, centers and variance-normalizes both residual and context sketches, and penalizes the mean squared cross-covariance between them. Train with ordinary next-character cross-entropy on every iteration; after warmup_iters and every orthogonality_interval iterations, add a small ramped lambda_ortho times this loss, sweeping lambda values such as 0.005, 0.01, and 0.05. Extend estimate_loss to report ordinary train and validation NLL as the primary metric, residual-context covariance norm, expected calibration error, Brier score, validation loss by local-frequency bucket, repeated-target versus novel-target loss, train-val gap, total train time, and unchanged inference tokens per second. Compare against the baseline, uniform label smoothing, a shuffled-context-sketch control, and a residual-norm penalty control across shakespeare_char, enwik8, and text8.
