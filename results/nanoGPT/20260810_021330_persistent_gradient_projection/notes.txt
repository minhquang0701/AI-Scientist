# Title: Persistent Gradient Projection for Low-Noise Autoregressive Language Model Training
# Experiment description: Add an optional optimizer-side persistent gradient projection filter to the existing training loop. Introduce settings such as use_persistent_gradient_projection, grad_ema_beta, projection_strength, projection_ramp_iters, min_projection_cosine, and min_projected_params. After scaler.scale(loss).backward(), call scaler.unscale_(optimizer) once before gradient clipping when the filter is active. Maintain one detached slow EMA buffer per trainable parameter tensor using the current unscaled gradient. After warmup_iters, ramp projection_strength from 0 to its target value. For each sufficiently large parameter tensor, compute the cosine similarity between the current gradient g and the bias-corrected EMA direction e. If the cosine exceeds min_projection_cosine, decompose g into a parallel component along e and an orthogonal residual, then replace the gradient with g_parallel + (1 - projection_strength_t * cosine) * g_orthogonal. If the tensor is small or agreement is low, leave its gradient unchanged. Keep the GPT architecture, data loader, objective, validation, generation, and final reporting unchanged. Compare baseline AdamW against projection settings with grad_ema_beta values 0.98 and 0.995 and projection_strength values 0.25, 0.5, and 0.75 across shakespeare_char, enwik8, and text8. Include a simple control that adds the gradient EMA like extra momentum without orthogonal projection. Report best validation loss, convergence speed, train-validation gap, total train time, inference tokens per second, generated samples, layerwise gradient-EMA cosine agreement, and effective update norm.
