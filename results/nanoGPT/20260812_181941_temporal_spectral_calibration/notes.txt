# Title: Temporal Spectral Calibration for Autoregressive Character Models
# Experiment description: Keep the GPT architecture, data loader, optimizer, evaluation path, and generation code unchanged. Add a temporal_spectral_calibration_loss(logits, targets, chunk_len=64, num_coeffs=8) helper. For each non-overlapping chunk, compute softmax probabilities from the model logits and project the predicted probability sequence for each character onto the first few orthonormal DCT basis vectors over time. Build matching target coefficients by accumulating the same basis values into the observed target character ids, with ignore_index support and no dense one-hot tensor. Penalize the Huber or MSE gap between predicted and realized low-frequency coefficients, optionally weighting coefficient k by 1 / (1 + k). Train with ordinary next-character cross-entropy on every iteration; after warmup_iters, every spectral_interval iterations, add a small ramped lambda_spectral times this loss. Extend estimate_loss to report ordinary train and validation loss as the primary metric, spectral coefficient error, DC-only marginal error, expected calibration error, generated character-frequency KL, repeated n-gram rate, and distinct n-gram fraction. Compare the baseline, DC-only local marginal calibration, temporal spectral calibration, and a shuffled-time target control across shakespeare_char, enwik8, and text8, with small ablations over chunk_len and num_coeffs. Generation remains unchanged, so inference tokens per second should be unaffected.
