# Title: Attention Span Curriculum for Context-Robust Character Language Models
# Experiment description: Modify CausalSelfAttention.forward to accept an optional attn_span argument. If attn_span is None or greater than or equal to the current sequence length, use the existing full causal attention path. Otherwise, use an explicit banded causal mask so each token attends only to itself and the previous attn_span - 1 tokens; for flash attention, pass this mask through scaled_dot_product_attention rather than using is_causal=True. Propagate attn_span through Block.forward, GPT.forward, and GPT.generate. In the training loop, keep the ordinary next-token cross-entropy objective unchanged, but sample attn_span from values such as [32, 64, 128, 256]. Use a simple curriculum that starts with more probability on short spans and linearly anneals toward mostly full-span attention, ending with full span sampled with high probability such as 0.75. Extend estimate_loss to report validation loss under fixed attention spans 32, 64, 128, and 256, with full-span validation loss as the primary metric. Keep default generation full-context, but optionally benchmark generation quality and tokens per second under fixed attn_span values. Log sampled span, full-span validation loss, mean local-span validation loss, local-to-full degradation, total train time, and inference tokens per second. Compare against the baseline and context-length dropout to test whether regularizing attention connectivity, while keeping full-length supervision and positional coverage, improves robustness to reduced context access without adding parameters.
