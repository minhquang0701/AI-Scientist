# Title: Stateful Causal Cipher Equivariance for Character Language Models
# Experiment description: Add a lightweight finite-state cipher augmentation for character batches. Before training each dataset, create 2 to 4 fixed random vocabulary permutations, optionally leaving simple structural tokens such as space and newline unchanged. Add apply_stateful_cipher(chunk), where chunk = torch.cat([X[:, :1], Y], dim=1). Starting from state 0, transform each token as z_t = perm[state_t][chunk_t], then update state_{t+1} = (state_t + update_bucket[chunk_t]) mod num_states using only the already visible original token; because the current state and transformed token determine the original token, the cipher is causally invertible. Return X_cipher = z[:, :-1], Y_cipher = z[:, 1:], and state[:, 1:] for target-position logit permutation. In train(), always optimize ordinary clean next-character cross-entropy. After warmup_iters, every cipher_interval iterations, run one extra forward pass on X_cipher and Y_cipher, adding a small ramped auxiliary loss consisting of cipher CE plus optional temperature-2 KL from detached clean logits permuted into the aligned cipher vocabulary. Keep ordinary validation and generation unchanged. Extend estimate_loss to report clean validation loss, held-out ciphered validation loss, clean-to-cipher equivariance KL, rare-token validation loss, train-val gap, total train time, and generation tokens per second. Compare the baseline, static symbol-permutation augmentation, stateful causal cipher augmentation, and a shuffled-state control across shakespeare_char, enwik8, and text8.
