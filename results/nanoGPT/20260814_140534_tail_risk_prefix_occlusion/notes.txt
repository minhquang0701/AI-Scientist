# Experiment description: Add a learned mask_embedding to GPT and modify GPT.forward(idx, targets=None, input_mask=None) so masked input positions replace token embeddings before positional embeddings while the default path remains unchanged. After warmup_iters and every occlusion_interval iterations, protect a recent suffix such as the final 96 or 128 tokens, sample a small number M such as 3 or 4 structured old-prefix occlusion masks using random spans and distance bands, stack the masked views along the batch dimension, and run one auxiliary masked forward. Compute suffix-averaged NLL per sequence for the clean and masked views, form positive excess degradation clamp(masked_suffix_nll - clean_suffix_nll.detach(), min=0), and add a ramped CVaR-style loss over the worst masked views, using either top-q averaging or a soft logmeanexp tail objective. Keep clean CE dominant and leave generation unchanged by calling forward without input_mask. Extend estimate_loss to report clean validation loss, mean masked validation loss, worst-of-M masked validation loss, CVaR excess degradation, repeated-target versus novel-target loss, previous-occurrence-distance buckets, train-val gap, total train time, and unchanged clean generation tokens per second. Compare the baseline, single-view random prefix masking, average masked-loss training, and tail-risk prefix occlusion across shakespeare_char, enwik8, and text8.
