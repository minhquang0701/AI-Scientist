# Title: Leave-One-Block Dominance for Non-Degrading Residual Transformer Refinement
# Experiment description: Modify Block.forward to accept a residual_scale argument that scales both attention and MLP residual updates, with residual_scale=1 preserving the baseline and residual_scale=0 skipping that block. Modify GPT.forward to accept a fixed-length layer_scales vector, defaulting to all ones so evaluation and generation are unchanged. In train(), optimize ordinary full-depth next-character cross-entropy as usual. After warmup_iters and every dominance_interval iterations, sample one transformer block and run a deterministic auxiliary comparison with dropout disabled: compute a no-grad leave-one-block-out forward on the same X,Y with the sampled block skipped, then compute a trainable full-depth forward. Use the trainable full-depth loss as the CE-bearing loss for that update, and add a small ramped one-sided penalty mean(relu(full_nll - skip_nll.detach() + dominance_margin)) on valid tokens, with dominance_margin set to 0.0 or a tiny value. Optionally apply the penalty only where the skipped model has moderate confidence to avoid ambiguous-token noise. Restore normal training mode afterward. Extend estimate_loss to report ordinary validation loss plus leave-one-block degradation for each layer. Log negative-contribution rate, mean skip_nll - full_nll by sampled layer, train-val gap, total train time, and unchanged full-depth generation tokens per second. Compare the baseline, leave-one-block dominance, a compute-matched extra-full-forward control, and random skipped-layer augmentation across shakespeare_char, enwik8, and text8.
