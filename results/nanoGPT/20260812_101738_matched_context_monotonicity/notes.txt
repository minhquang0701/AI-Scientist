# Title: Matched-Position Context Monotonicity for Non-Interfering Long-Context Language Models
# Experiment description: Modify GPT.forward(idx, targets=None, position_ids=None) so the default path is unchanged, but optional position_ids can index learned positional embeddings for controlled comparisons. After warmup_iters, every monotonic_interval iterations such as 4 or 8, sample one shorter suffix length L from values such as 32, 64, or 128. Run an additional forward pass on X[:, -L:] and Y[:, -L:] using matched absolute position_ids corresponding to positions block_size - L through block_size - 1. Compute unreduced target negative log likelihoods for the aligned final L positions from the full-context logits and the matched-position short-context logits. Add a small ramped hinge penalty mean(relu(full_nll - short_nll - margin)), with the short-context losses detached so the auxiliary term only discourages the full-context path from being worse than the shorter-context view. Keep the ordinary full-context CE as the dominant objective and leave generation unchanged. Extend estimate_loss() to report ordinary validation loss at context lengths 32, 64, 128, and 256, matched-position negative-context-interference rate, mean interference magnitude, and validation loss on high-interference positions. Compare against the baseline, context-length dropout, and a compute-matched extra-forward control across shakespeare_char, enwik8, and text8 using best full-context validation loss, short-context robustness, interference rate, train-val gap, total train time, and unchanged generation tokens per second.
