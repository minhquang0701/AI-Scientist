# Title: Event-Time Attention for Learned Causal Recency in Character Transformers
# Experiment description: Extend GPTConfig with use_event_time_attention, event_time_min, event_time_max, event_time_slope_max, and event_time_log_duration_l2. In GPT.__init__, add a duration_head Linear(n_embd, 1) initialized to produce durations near 1.0. In GPT.forward, after token embeddings are computed, predict positive per-position durations, clamp them to a conservative range, normalize each sequence so the mean duration is 1, and form cumulative event-time coordinates. Pass event_time through Block.forward into CausalSelfAttention.forward. When enabled, use the manual causal attention path and add a monotone per-layer per-head distance penalty -s_h * log1p(max(event_time_q - event_time_k, 0)), where s_h is bounded, nonnegative, and initialized to zero so the model starts as a manual-attention baseline. Train with ordinary next-character cross-entropy plus a small log-duration L2 penalty to discourage extreme clocks. Evaluation and generation recompute event time from the visible context and otherwise stay unchanged. Compare flash-attention baseline, manual-attention no-bias control, fixed token-distance bias, learned event-time attention, and shuffled-duration control across shakespeare_char, enwik8, and text8. Report best validation loss, train-val gap, validation loss at context lengths 64/128/256, repeated-target versus novel-target loss, previous-occurrence-distance buckets, learned duration statistics by character class, attention distance profiles in token time versus event time, total train time, and inference tokens per second.
