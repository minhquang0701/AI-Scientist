# Title: Soft-Text Gradient Replay for Condensed Character Language Modeling
# Experiment description: Add a train-only SoftTextReplayBank containing a small number of learnable token-logit windows of length block_size + 1, initialized from random train.bin chunks. Modify GPT.forward to optionally accept inputs_embeds and return final hidden states after ln_f, leaving the normal idx path unchanged. Build synthetic inputs as softmax(bank_logits[:, :-1]) @ transformer.wte.weight and synthetic targets as softmax(bank_logits[:, 1:]). Add soft_cross_entropy and an output_gradient_sketch helper that uses fixed random projections of hidden states and prediction residuals. During training, optimize ordinary real next-character CE on every iteration. After warmup_iters, every condense_interval, freeze GPT parameters and update only the replay bank for a few steps to match the detached gradient sketch of a fresh real batch, with small entropy and diversity regularizers. Every replay_interval, add a ramped soft-replay CE loss to the GPT update. Compare CE-only baseline, random real-window replay with matched extra compute, static soft replay without gradient matching, and soft-text gradient replay across shakespeare_char, enwik8, and text8. Include a frozen-bank transfer diagnostic where a learned bank is reused for a fresh seed. Report validation loss, best validation loss per step and wall-clock time, train-val gap, seed variance, frozen-bank transfer gain, synthetic entropy/diversity, total train time, and unchanged generation tokens per second.
