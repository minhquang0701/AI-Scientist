# Title: Position-Matched Context Advantage Prediction for Selective Autoregressive Context Use
# Experiment description: Modify GPT.forward to optionally return final hidden states and per-token cross-entropy losses by using F.cross_entropy(..., reduction='none') reshaped to batch by time. Also add an optional position_offset argument so a cropped suffix can reuse the same learned absolute position indices as it had inside the full block. Extend GPTConfig with use_context_advantage_head, context_advantage_weight, context_advantage_ramp_iters, context_probe_len, context_advantage_interval, and context_advantage_scale. In GPT.__init__, add a scalar context_advantage_head from the final hidden state, for example LayerNorm followed by Linear(n_embd, 1). During training, compute the ordinary full-context forward pass on X,Y and optimize the standard mean next-character cross-entropy as the primary loss. After warmup_iters and only every context_advantage_interval iterations, run a no-gradient cropped-context probe on X[:, -context_probe_len:] and Y[:, -context_probe_len:] using position_offset=block_size-context_probe_len. Align this probe with the final context_probe_len positions of the full-context pass and define a detached target advantage as clamp((nll_short - nll_full) / context_advantage_scale, 0, 1), so only positions where longer context improves true-token likelihood receive high targets. Predict this bounded advantage from the corresponding full-context hidden states and add a ramped mean-squared-error auxiliary loss. Keep estimate_loss, best validation loss, generation, final reporting, and inference speed based on the ordinary lm_head only. Add diagnostics for context-advantage prediction error, average predicted advantage by position and token-loss quantile, validation loss stratified by predicted advantage, and cropped-context validation losses at 64 and 128 tokens with matched position offsets. Compare the baseline against context_probe_len values 64 and 128 with context_advantage_weight values 0.02, 0.05, and 0.1 across shakespeare_char, enwik8, and text8.
