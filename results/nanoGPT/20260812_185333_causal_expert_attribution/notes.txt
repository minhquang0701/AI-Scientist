# Title: Causal Expert Attribution for Self-Supervised Predictability Decomposition
# Experiment description: Modify GPT.forward() to optionally return final hidden states after ln_f. Before training each dataset, scan train.bin once to compute a smoothed unigram distribution. Add lightweight helpers that compute, for each supervised batch position, the true-target negative log likelihood under three causal heuristic experts: the global unigram model, a recent-window count model over the visible prefix using a window such as 64 tokens, and a suffix-match copy model that uses previous matching suffixes of length 2 or 4 within the same sequence to predict the following character. Smooth all expert probabilities with the unigram distribution so losses are finite. Add a training-only expert_attribution_head Linear(n_embd, num_experts). Train every iteration with ordinary next-character cross-entropy. After warmup_iters, every attribution_interval iterations, reuse the normal forward pass with return_hidden=True, convert detached expert NLLs into soft oracle responsibilities using softmax(-expert_nll / attribution_temperature), and add a small ramped KL loss from the responsibilities to the attribution head predictions, with lambda_attr capped around 0.05 or 0.1. Evaluation and generation ignore the attribution head and use the original lm_head unchanged. Extend estimate_loss() to report ordinary train/validation loss as the primary metric, attribution KL, dominant-expert accuracy, responsibility entropy, validation loss by dominant oracle expert, repeated-target versus novel-target loss, train-val gap, total train time, and unchanged inference tokens per second. Compare against the baseline, shuffled-responsibility control, hard best-expert-label auxiliary control, and a detached-hidden diagnostic where the attribution head is trained without shaping the GPT representations.
