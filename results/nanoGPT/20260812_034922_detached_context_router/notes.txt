# Title: Detached Context Routing for Efficient Adaptive-Window Language Modeling
# Experiment description: Add a lightweight context_router head to GPT that maps the final hidden state from a short suffix context to logits over candidate context lengths such as 32, 64, 128, and 256. Modify GPT.forward() to optionally return final hidden states. Train the base language model exactly as before with ordinary full-context next-token cross-entropy. After warmup_iters, every router_interval iterations, run no-grad forward passes on the same batch sliced to the candidate suffix lengths and compare each candidate's final-token prediction to the full 256-context prediction using excess target loss or KL divergence. Assign each sequence an oracle label equal to the shortest context whose regret is below a fixed threshold, otherwise 256. Train only the router head from the detached 32-context final hidden state using cross-entropy, so router learning does not alter the LM representations. Extend estimate_loss() to report ordinary full-context validation loss, fixed-context final-token losses, oracle adaptive-context loss, predicted adaptive-context loss, router accuracy, long-context recall, and mean selected context length. Add generate_adaptive_context() that first evaluates the last 32 tokens, uses the router to select a context length, reuses the 32-token logits if selected, otherwise reruns with the selected longer suffix before sampling. Compare full-context generation, fixed short-context generation, entropy-threshold routing, random budget-matched routing, and learned detached routing across shakespeare_char, enwik8, and text8 using validation loss, generation tokens per second, mean processed context length, and speed-quality tradeoff curves.
