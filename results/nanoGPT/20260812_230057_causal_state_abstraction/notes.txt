# Title: Causal-State Abstraction for Predictive Context Representations in Character Language Models
# Experiment description: Before training each dataset, scan train.bin once to build capped suffix-to-next-character count tables for short causal suffix lengths such as 4, 6, and 8, retaining only the most frequent supported contexts. Smooth each retained context's next-character distribution with the train-set unigram distribution, then cluster these distributions with deterministic numpy k-means into a modest number of predictive causal states such as 32 or 64. Add a helper that labels batch positions by looking up the longest supported visible suffix ending at each input position, returning -1 when no supported suffix is found. Modify GPT.forward() to optionally return final hidden states after ln_f, and add a training-only causal_state_head Linear(n_embd, num_causal_states). Train every iteration with ordinary next-character cross-entropy as the primary objective; after warmup_iters, every state_interval iterations, compute causal-state labels for the current batch and add a small ramped auxiliary cross-entropy from causal_state_head(hidden_states) to those labels, ignoring -1 positions. Evaluation and generation use only the standard lm_head. Extend estimate_loss() to report ordinary train/validation loss, causal-state accuracy on supported validation contexts, validation loss on supported versus unsupported contexts, validation loss by predictive-state entropy bucket, train-val gap, total train time, and unchanged generation tokens per second. Compare against the baseline, random state labels with matched support, support-bucket-only labels, and direct n-gram soft-target smoothing across shakespeare_char, enwik8, and text8.
