# Title: Latent Prefix Imputation for Uncertainty-Aware Missing-Context Language Modeling
# Experiment description: Add a learned mask_embedding and an optional input_mask argument to GPT.forward so selected input tokens can be hidden while default training, evaluation, and generation remain unchanged. Train ordinary next-character cross-entropy every iteration. After warmup_iters and every impute_interval iterations, use a small auxiliary subbatch, choose one older-prefix position m per sequence, and reserve a later protected suffix for regularization. From the detached clean logits at position m - 1, take the top-k candidate identities for X[:, m]. Build k branch views with X[:, m] replaced by each candidate. Under torch.no_grad(), score only the observed evidence tokens between m and the protected suffix to form posterior weights over candidates, then compute a posterior-mixture teacher distribution on the protected suffix by log-mean-exp averaging branch log probabilities. Run one trainable masked forward pass where X[:, m] is replaced by mask_embedding, and add a small ramped KL loss from the posterior-mixture teacher to the masked-view suffix logits. Extend estimate_loss to report clean validation loss, masked-prefix validation loss, masked-to-mixture KL, posterior entropy, and loss by distance from the hidden token. Compare against the baseline, clean-to-mask distillation, uniform top-k branch mixtures, and random prefix masking across shakespeare_char, enwik8, and text8.
