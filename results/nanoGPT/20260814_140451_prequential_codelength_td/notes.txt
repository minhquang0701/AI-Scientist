# Title: Prequential Codelength TD for Predictive-State Language Modeling
# Experiment description: Modify GPT.forward to optionally return final hidden states after ln_f. Add a training-only value_head Linear(n_embd, 1) that predicts discounted future codelength from each hidden state. Train with the ordinary next-character cross-entropy on every iteration. After warmup_iters and every value_interval iterations, compute unreduced per-token NLL from the current logits, detach it, and build a truncated discounted return target G_t = sum_{k=0}^{H-1} gamma^k nll_{t+k}, masking positions without enough future context. Add a small ramped Huber loss between value_head(hidden_t) and G_t. After the value head has warmed up, optionally add a weak one-step TD consistency penalty value_t ≈ detach(nll_t + gamma * value_{t+1}). Evaluation and generation ignore the value head and use the standard lm_head unchanged. Extend estimate_loss to report ordinary validation loss as the primary metric, value prediction error, TD residual, correlation between predicted codelength and realized future NLL, validation loss by predicted-codelength bucket, expected calibration error, train-val gap, total train time, and unchanged inference tokens per second. Compare against the baseline, a detached-hidden value probe that does not shape GPT representations, fixed-horizon future-NLL regression without TD consistency, and shuffled-return controls across shakespeare_char, enwik8, and text8.
