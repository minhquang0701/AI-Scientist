# Title: Decaying Simplex Anchors for Tied Character Embeddings
# Experiment description: Add an optional simplex-frame initialization and early decaying anchor for the tied token/output embedding matrix. For vocab_size <= n_embd + 1, initialize transformer.wte.weight from a centered regular-simplex-like row geometry, scaled to match the baseline embedding standard deviation; otherwise use a normalized random frame approximation. Add a simplex_frame_loss(weight) helper that L2-normalizes rows, penalizes nonzero embedding mean, and penalizes deviation of the row Gram matrix from the simplex target with diagonal 1 and off-diagonal -1 / (vocab_size - 1). In train(), keep ordinary next-character cross-entropy as the primary objective and optionally add lambda_frame * simplex_frame_loss only after warmup, decaying lambda_frame to zero by mid-training so the embedding geometry can adapt. Compare baseline random initialization, row-norm-only control, simplex warm start only, decaying simplex anchor only, and warm start plus decaying anchor across shakespeare_char, enwik8, and text8. Report best validation loss, convergence speed, train-val gap, rare versus common token loss, expected calibration error, embedding pairwise cosine statistics, embedding mean norm, seed variance, total train time, and unchanged inference tokens per second.
