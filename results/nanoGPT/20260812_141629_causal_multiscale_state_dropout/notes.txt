# Title: Causal Multiscale State Dropout for Scale-Robust Autoregressive Transformers
# Experiment description: Modify GPT.forward() to optionally apply a train-time multiscale hidden-state perturbation after a fixed middle block such as block 3. Add a helper that computes edge-corrected causal moving averages of hidden states with cumulative sums using two windows such as 16 and 64. Decompose the hidden state h into fast = h - ma16, medium = ma16 - ma64, and slow = ma64. When enabled, randomly choose one component per batch, attenuate it by a scheduled factor ramping from 0.0 to about 0.5, recombine the components, and continue through the remaining transformer blocks. Keep the default forward path and generation path unchanged. In train(), always compute ordinary clean next-character cross-entropy. After warmup_iters, every state_dropout_interval iterations, run one additional perturbed forward pass on the same X and Y, adding a ramped auxiliary loss consisting of perturbed cross-entropy plus temperature-2 KL consistency from detached clean logits to perturbed logits. Extend estimate_loss() to report ordinary train and validation loss as the primary metric, validation loss under fixed fast-drop, medium-drop, and slow-drop perturbations, clean-to-perturbed KL, train-val gap, total train time, and unchanged clean generation tokens per second. Compare against the baseline, Gaussian hidden-state jitter at the same layer, and input token dropout controls across shakespeare_char, enwik8, and text8.
