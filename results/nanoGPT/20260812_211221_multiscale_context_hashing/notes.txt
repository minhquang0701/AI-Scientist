# Title: Multi-Scale Causal Context Hashing for Order-Sensitive Memory Supervision
# Experiment description: Add a lightweight training-only auxiliary task that asks hidden states to predict compact rolling-hash summaries of recent causal context windows. After loading vocab_size, initialize fixed random token maps and modular multipliers for several independent hashes. Use window sizes such as 16, 64, and 256, and compute labels h_t = hash(X[:, max(0, t - W + 1):t + 1]) for each position, window, and hash, with a simple loop over the 256-token block. Modify GPT.forward() to optionally return final hidden states after ln_f, and add a hash_head Linear(n_embd, num_windows * num_hashes * num_hash_states) used only during training and diagnostics. Train with ordinary next-character cross-entropy on every iteration; after warmup_iters, every hash_interval iterations, add a small ramped auxiliary cross-entropy from hash_head(hidden_states) to the hash labels, with lambda_hash in the range 0.02 to 0.10. Evaluation and generation ignore the hash head and use the standard lm_head. Extend estimate_loss to report ordinary validation loss, hash prediction accuracy by window size, validation loss at context lengths 64 and 256, repeated-target versus novel-target loss, and train-val gap. Compare against the baseline, shuffled hash labels, prefix-count supervision with similar head size, and ablations over window sizes and num_hash_states across shakespeare_char, enwik8, and text8.
