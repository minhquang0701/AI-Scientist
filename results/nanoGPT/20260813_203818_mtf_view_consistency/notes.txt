# Title: Move-to-Front View Consistency for Recency-Robust Character Language Modeling
# Experiment description: Add an MTFCodec helper that reconstructs each sampled chunk as torch.cat([X[:, :1], Y], dim=1), encodes it into move-to-front ranks, and returns X_mtf, Y_mtf, plus per-position char_to_rank maps after each visible prefix. Extend GPTConfig and GPT with a learned two-entry view embedding added to token and position embeddings, using view_id=0 for ordinary raw characters and view_id=1 for MTF ranks. Train every iteration with standard raw next-character cross-entropy. After warmup_iters, every mtf_interval iterations, run an auxiliary MTF forward pass on the same chunk, add a small rank-space cross-entropy loss, map MTF log probabilities back into canonical character space with char_to_rank, and add a ramped temperature-2 KL loss from detached raw-view probabilities to mapped MTF probabilities. Keep validation and default generation on the raw view only. Extend estimate_loss to report raw validation loss, MTF rank loss, mapped raw-to-MTF KL, repeated-target versus novel-target loss, loss by previous-occurrence distance bucket, and generation tokens per second. Compare the baseline, raw plus MTF CE without KL, raw plus MTF consistency, a shuffled char_to_rank consistency control, and an MTF-only representation control across shakespeare_char, enwik8, and text8.
