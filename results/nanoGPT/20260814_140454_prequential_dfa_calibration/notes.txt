# Title: Prequential DFA Calibration for Structured Autoregressive Forecasts
# Experiment description: Keep the GPT architecture, optimizer, data loader, evaluation path, and generation code unchanged. After loading each dataset vocabulary, build a small bank of deterministic finite automata over frequency-balanced token groups, with separate train and held-out diagnostic automata. Add compute_dfa_states(X, automata) to scan each visible prefix and return the current DFA state at every position. Add dfa_calibration_loss(logits, targets, current_states, automata), which sums softmax token probabilities into the model-implied distribution over next DFA states, masks trivial current states whose outgoing transitions collapse to one state, and applies a bounded Brier loss to the true next state induced by the target token. Train with ordinary next-character cross-entropy on every iteration; after warmup_iters and every dfa_interval iterations, add a small ramped lambda_dfa times this loss. Extend estimate_loss to report ordinary train/validation NLL as the primary metric, DFA-state Brier and NLL, held-out automata calibration, validation loss by DFA state, generated-sample DFA state-frequency error, train-val gap, total train time, and unchanged inference tokens per second. Compare against the CE-only baseline, static partition calibration, shuffled-DFA controls, random state-label controls, and local marginal calibration across shakespeare_char, enwik8, and text8.
