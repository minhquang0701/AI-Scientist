# Title: In-Context Pointer-Jumping Curricula for Compositional Character Memory
# Experiment description: Add a get_pointer_jump_batch() helper that generates synthetic auxiliary windows using only token ids from the current dataset vocabulary. Reserve a few existing high-frequency tokens as separator, query, and hop markers, excluding them from map symbols; if the vocabulary is small, shrink the map size and hop range. Each sequence writes a visible functional map or small permutation in the prefix as repeated separator-key-value triples, then places sparse queries encoded as query marker, h repeated hop markers, and a start symbol. The supervised target is only the answer token f^h(start), with all other targets set to -1. Use a simple curriculum that begins with one-hop queries and gradually includes two- to four-hop queries plus distractor map entries. In train(), keep ordinary real-text next-character cross-entropy on every iteration; after warmup_iters, every pointer_interval iterations, add one pointer-jump batch with total_loss = lm_loss + lambda_pointer * pointer_loss, ramping lambda_pointer to 0.05 to 0.15. Extend diagnostics with pointer-jump accuracy by hop count, including held-out deeper hops, map size, and distractor density, while reporting ordinary validation loss, repeated-target loss, train-val gap, total train time, and unchanged generation tokens per second. Compare the baseline, one-hop binding-only curriculum, pointer-jump curriculum, shuffled-answer control, and compute-matched random synthetic control across shakespeare_char, enwik8, and text8.
