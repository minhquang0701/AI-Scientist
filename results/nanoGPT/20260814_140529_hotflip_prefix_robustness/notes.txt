# Title: HotFlip Prefix Robustness for Discrete Adversarial Character Language Modeling
# Experiment description: Modify GPT.forward to optionally accept inputs_embeds while preserving the default idx path for ordinary training, evaluation, and generation. Add hotflip_prefix_replacements(model, X, Y, suffix_len=64, max_flips=1 or 2), which runs a suffix-only loss with gradients to the input embeddings, scores replacement characters by the first-order HotFlip score grad dot (embedding_candidate - embedding_original), and edits only older-prefix positions before the protected suffix. Because the vocabulary is small, score all valid character ids, with an optional top-frequency candidate restriction as an ablation. In train(), always optimize the standard clean next-character cross-entropy. After warmup_iters and every hotflip_interval iterations, build X_adv using the HotFlip edits, run one additional forward pass, and add a small ramped adversarial suffix loss, optionally with a temperature-2 KL term from detached clean suffix logits to adversarial suffix logits. Keep default generation unchanged. Extend estimate_loss to report clean validation loss, random-prefix-substitution validation loss, HotFlip-prefix validation loss, clean-to-adversarial KL, adversarial recovery by distance into the suffix, train-val gap, total train time, and clean generation tokens per second. Compare against the baseline, random discrete prefix substitutions, continuous embedding adversarial training, and gradient-salience prefix erasure across shakespeare_char, enwik8, and text8.
