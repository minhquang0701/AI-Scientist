# Title: Causal Attention-Rollout Coverage for Multi-Hop Context Use
# Experiment description: Modify CausalSelfAttention.forward to optionally return attention probabilities, using the manual causal attention path only when return_attention=True. Propagate return_attention through Block.forward and GPT.forward while keeping the default flash-attention training, evaluation, and generation paths unchanged. Train with the ordinary full-batch next-character cross-entropy on every iteration. After warmup_iters, every rollout_interval iterations, take a small sampled subbatch, run an auxiliary forward pass with attention maps enabled, average attention over heads in each layer, form residual-aware maps A_tilde = residual_mix * I + (1 - residual_mix) * A with residual_mix around 0.5, and estimate rollout only for sampled suffix query positions by propagating query distributions backward through the layer maps. Aggregate rollout mass into logarithmic causal distance bands such as 0-15, 16-63, 64-127, and 128-255, ignoring unavailable bands near the left boundary. Add a small ramped hinge penalty that prevents medium- and far-band rollout mass from collapsing below conservative floors, while keeping cross-entropy dominant. Extend estimate_loss to report ordinary validation loss, validation losses at context lengths 64, 128, and 256, rollout mass by distance band, rollout entropy, repeated-target versus novel-target loss, loss by previous-occurrence distance, train-val gap, total train time, and default generation tokens per second. Compare against the baseline, a manual-attention no-regularizer control, per-layer distance-coverage regularization, and an attention-entropy-floor control across shakespeare_char, enwik8, and text8.
