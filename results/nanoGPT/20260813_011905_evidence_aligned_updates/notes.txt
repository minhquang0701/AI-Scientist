# Title: Evidence-Aligned Predictive Updates for Autoregressive Language Models
# Experiment description: Keep the GPT architecture, evaluation path, and generation code unchanged. Before training each dataset, compute a smoothed unigram token distribution from train.bin. Add a build_causal_transition_evidence(X, vocab_size, unigram_prior, smoothing) helper that, for each sequence position t, uses only earlier in-window transitions X[p] -> X[p+1] with p < t to estimate a smoothed distribution q(. | X[t]) and its support count. In the training loop, compute ordinary next-character cross-entropy every iteration. After warmup_iters, every align_interval iterations such as 4, compute log probabilities from the same logits and form adjacent predictive update vectors delta_model = log p_t - detach(log p_{t-1}) for t >= 1. Form detached evidence update vectors delta_evidence = log q(. | X[t]) - log unigram_prior, center both vectors across the vocabulary, and add a ramped cosine alignment loss gate * (1 - cosine(delta_model, delta_evidence)), where gate = support / (support + tau). Keep CE dominant with lambda_align values such as 0.01, 0.05, and 0.1. Extend estimate_loss to report ordinary train and validation loss as the primary metric, update-evidence cosine alignment, predictive JS drift by transition-support bucket, validation loss on repeated-transition versus novel-transition positions, train-val gap, total train time, and unchanged generation tokens per second. Compare against the baseline, shuffled-evidence-vector control, direct local-transition-prior fusion control, and magnitude-only update-smoothing control across shakespeare_char, enwik8, and text8.
