# Title: Switching-Compressor Regret for Sequentially Adaptive Character Language Models
# Experiment description: Keep the GPT architecture, data loader, evaluation path, and generation code unchanged. Before training each dataset, compute a smoothed unigram prior from train.bin. Add lightweight causal expert helpers that use only visible in-window context to score the true next character: unigram, recent-window count models with windows 16 and 64, in-context bigram transitions, and suffix-copy models with suffix lengths 2 and 4. During training, compute ordinary next-character cross-entropy every iteration. After warmup_iters and every regret_interval iterations, compute detached per-token NLLs and support counts for all experts on the current batch, then run a small Viterbi dynamic program per sequence with switch costs such as 0.5 and 1.0 nats to find the best temporally coherent expert path. Add a conservative one-sided auxiliary penalty on valid supported positions, gate * relu(model_nll - oracle_nll - margin)^2, where gate depends on selected-expert support and lambda_regret ramps to 0.02, 0.05, or 0.1. Extend estimate_loss to report ordinary train and validation loss as the primary metric, switching-oracle NLL, model regret to the oracle, selected expert fractions, average segment length, repeated versus novel target loss, validation loss by selected oracle regime, train-val gap, total train time, and unchanged inference tokens per second. Compare against the baseline, per-token best-expert regret without switch costs, fixed local-prior fusion, and a shuffled-expert-loss control across shakespeare_char, enwik8, and text8.
