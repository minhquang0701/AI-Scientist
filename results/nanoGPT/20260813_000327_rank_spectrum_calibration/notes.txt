# Title: Rank-Spectrum Logit Calibration for Character-Level Language Models
# Experiment description: Extend GPTConfig with use_rank_spectrum_calibration, num_rank_buckets, rank_calibration_init, rank_calibration_l2, and rank_smooth_l2. Initialize all corrections to zero so the enabled model starts exactly as the baseline. Modify GPT.forward so the tied lm_head first produces ordinary base logits, then optionally applies the rank-spectrum correction before computing cross-entropy. Keep generation unchanged except that enabled models sample from calibrated logits; also add a diagnostic path to evaluate base logits without calibration. Train with ordinary next-character cross-entropy plus small L2 and adjacent-bucket smoothness penalties on the rank corrections after warmup_iters. Extend estimate_loss to report calibrated validation loss, base-only validation loss, expected calibration error, Brier score, nucleus coverage error, target-rank histograms, learned rank correction values, generated character-frequency KL, repeated-character rate, distinct n-gram fraction, and inference tokens per second. Compare the baseline, learned global temperature, uniform label smoothing, and rank-spectrum calibration across shakespeare_char, enwik8, and text8.
