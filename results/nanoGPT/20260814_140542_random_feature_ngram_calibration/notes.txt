# Title: Random-Feature N-Gram Calibration for Sequence-Level Character Language Modeling
# Experiment description: Keep the GPT architecture, optimizer, data loader, ordinary validation, and generation path unchanged. After loading each dataset vocabulary, create fixed Rademacher random feature tables for each n-gram slot, with sketch_dim such as 64 or 128 and n-gram orders such as 2 and 3. Add random_feature_ngram_loss(logits, targets, orders=[2,3], chunk_len=64): compute softmax(logits), map each position's predictive distribution to an expected feature vector with probs @ feature_table, form model-implied n-gram features by elementwise multiplying the slot-specific expected features at adjacent positions, form empirical n-gram features from the observed target ids, average both over valid local chunks, and penalize their Huber or MSE difference. Train with ordinary next-character cross-entropy on every iteration; after warmup_iters and every ngram_cal_interval iterations, add a small ramped auxiliary weight such as lambda_ngram in {0.005, 0.01, 0.05}. Compare against CE-only training, local unigram marginal calibration, bigram-only calibration, shuffled-target n-gram controls, and uniform label smoothing across shakespeare_char, enwik8, and text8.
