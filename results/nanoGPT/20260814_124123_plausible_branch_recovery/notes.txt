# Title: Plausible Branch Recovery for Exposure-Robust Character Language Models
# Experiment description: Keep the GPT architecture, ordinary next-character cross-entropy objective, evaluation path, and default generation code unchanged. In train(), always compute the standard clean CE loss and clean logits. After warmup_iters and every branch_recovery_interval iterations, sample one shared anchor position with enough future context remaining. From detached clean logits at that anchor, sample a plausible non-gold replacement token for each sequence from the top_k candidates, excluding the observed target Y[:, anchor] when possible. Create a counterfactual batch by replacing only X[:, anchor + 1] with this sampled token while leaving the later teacher-forced tail unchanged. Run one extra forward pass on the counterfactual batch. After a short recovery burn-in, such as 4 or 8 positions, add a small ramped temperature-2 KL consistency loss from detached clean logits to counterfactual logits over the horizon anchor + burnin through anchor + H. Weight the KL by a clipped plausibility score for the replacement and downweight very high-entropy clean anchor predictions to avoid forcing consistency across genuinely ambiguous branches. Compare against the baseline, corrupted-prefix CE training, random-token replacement consistency, and a compute-matched extra-forward control across shakespeare_char, enwik8, and text8. Report ordinary validation loss as the primary metric, validation loss under plausible single-token branch corruptions, clean-to-branch recovery KL by distance from the branch point, expected calibration error, repeated n-gram diagnostics, train-val gap, total train time, and unchanged default generation tokens per second.
