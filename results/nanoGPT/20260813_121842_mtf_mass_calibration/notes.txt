# Title: Move-to-Front Mass Calibration for In-Context Character Prediction
# Experiment description: Keep the GPT architecture, optimizer, data loader, evaluation path, and generation code unchanged. Add compute_mtf_rank_buckets(X, Y, vocab_size, bucket_edges), which scans each sequence causally. After consuming X[:, t], each vocabulary token is assigned to a dynamic move-to-front bucket according to how recently that token type appeared in X[:, :t+1]: rank 0, rank 1, ranks 2-3, 4-7, 8-15, 16+, or unseen. Record both bucket ids for all vocabulary tokens at each batch-time position and the bucket containing the true target Y[:, t]. Add mtf_partition_loss(logits, bucket_ids, target_buckets), which computes log_softmax(logits), aggregates log probability mass per bucket with logsumexp, and applies cross-entropy to the true target bucket with ignore_index support. Train with ordinary next-character cross-entropy on every iteration; after warmup_iters, every mtf_interval iterations such as 4, add a ramped auxiliary term loss = ce_loss + lambda_mtf * mtf_partition_loss, sweeping lambda_mtf values such as 0.02, 0.05, and 0.1. Extend estimate_loss to report ordinary train and validation loss, MTF partition loss, partition accuracy, validation loss by target MTF bucket, seen versus unseen target loss, repeated-target versus novel-target loss, expected calibration error, train-val gap, total train time, and unchanged generation tokens per second. Compare against the baseline, a coarse seen-versus-unseen partition ablation, shuffled MTF buckets preserving bucket sizes, and a fixed unigram-frequency partition control across shakespeare_char, enwik8, and text8.
