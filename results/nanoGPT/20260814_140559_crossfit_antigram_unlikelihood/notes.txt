# Title: Cross-Fit Anti-N-Gram Unlikelihood for Negative Evidence in Character Language Models
# Experiment description: Partition each dataset's train.bin into K contiguous folds and build suffix-to-next-character count tables for suffix lengths such as 2, 4, and 6, storing total counts and per-fold counts. Modify get_batch() to return sampled offsets and fold ids. Train with ordinary next-character cross-entropy on every iteration. After warmup_iters and every antigram_interval iterations, look up the longest supported visible suffix for each token position using counts with the example's own fold subtracted. For high-support, low-entropy suffixes, define anti-continuation candidates as characters with zero or very low cross-fit count but nontrivial unigram frequency, excluding the true target. From these candidates, select a few detached high-probability negatives under the current model and add a capped support-gated unlikelihood loss, such as -log(1 - p_neg + eps), with a small ramped weight while keeping CE dominant. Extend estimate_loss to report ordinary validation loss as the primary metric, anti-continuation probability mass, validation false-negative diagnostics, high-support-context loss, expected calibration error, generated anti-continuation rate, train-val gap, total train time, and inference tokens per second. Compare against CE-only training, random-negative unlikelihood with matched negative counts, full-train anti-dictionaries without cross-fitting, and positive n-gram distillation across shakespeare_char, enwik8, and text8.
