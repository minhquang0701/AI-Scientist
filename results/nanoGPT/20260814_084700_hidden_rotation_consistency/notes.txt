# Title: Hidden Rotation Consistency for Coordinate-Robust Character Language Models
# Experiment description: Modify GPT.forward() to optionally apply a sparse norm-preserving hidden rotation after one selected middle transformer block, such as block 3 in the 6-layer model. Implement apply_givens_rotations(hidden, pair_ids, angles), which rotates disjoint hidden-channel pairs by small near-identity Givens angles while preserving each token hidden-state norm. During training, always compute the ordinary clean next-character cross-entropy. After warmup_iters and every rotation_interval iterations, run one additional rotated forward pass on the same X,Y using fixed-shape sampled channel pairs and ramped angle magnitude, then add a small temperature-2 KL consistency loss from detached clean logits to rotated logits. Keep evaluation and generation on the unchanged clean path. Extend estimate_loss() to report clean validation loss, rotated-path validation loss, clean-to-rotated KL, train-val gap, total train time, and clean generation tokens per second. Compare the baseline, matched-RMS Gaussian hidden jitter consistency, random channel sign-flip consistency, and hidden rotation consistency across shakespeare_char, enwik8, and text8, sweeping rotation angle, fraction of rotated channels, and auxiliary KL weight.
