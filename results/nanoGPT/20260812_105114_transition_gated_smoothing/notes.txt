# Title: Transition-Gated State Smoothing for Temporally Structured Character Language Models
# Experiment description: Modify GPT.forward() to optionally return final hidden states after ln_f. Add a small transition_head Linear(n_embd, 1) used only during training and diagnostics. Add a helper that computes self-supervised transition scores from each batch: using one-hot token indicators and cumulative sums, form normalized token histograms over a past window ending at each position and a future window beginning after that position, with window sizes such as 16 or 32. Define the transition score as the clipped Jensen-Shannon divergence between these two histograms, masking positions too close to the sequence edges. Keep ordinary next-character cross-entropy as the primary objective on every iteration. After warmup_iters, every transition_interval iterations, run the model with return_hidden=True, regress the transition_head output to the detached transition score, and add a small hinge regularizer on adjacent normalized hidden-state drift: penalize drift only when it exceeds a margin that increases with the transition score. Ramp lambda_transition from 0.0 to 0.05 or 0.1. Evaluation and generation use only the standard lm_head. Extend estimate_loss() to report ordinary train and validation loss, transition prediction MSE, hidden-state drift by transition-score bucket, validation loss on low-transition versus high-transition positions, train-val gap, total train time, and inference tokens per second. Compare against the baseline, ungated hidden-state smoothing, and shuffled-transition-score controls across shakespeare_char, enwik8, and text8.
