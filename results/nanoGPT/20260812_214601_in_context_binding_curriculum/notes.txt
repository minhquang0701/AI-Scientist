# Title: In-Context Binding Curricula for Relational Character Language Modeling
# Experiment description: Add a get_binding_batch() helper that creates synthetic associative-memory episodes using only token ids from the current dataset vocabulary and no special new tokens. For each sequence, sample unique key tokens and value tokens, optionally frequency-balanced across rare and common characters, write several key-value pairs into the prefix as consecutive two-token slots, then later repeat queried keys whose supervised next-token target is the associated value. Construct X and Y normally, but set Y to -1 everywhere except query-answer positions so the auxiliary objective isolates context-defined retrieval. Train ordinary real-data next-character cross-entropy every iteration. After warmup_iters, every binding_interval iterations, add one auxiliary binding batch with total_loss = lm_loss + lambda_binding * binding_loss, ramping lambda_binding to a conservative value such as 0.05 to 0.15. Keep the GPT architecture, standard validation, and generation unchanged. Evaluate on freshly sampled held-out maps while varying number of pairs, query delay, distractor tokens, repeated queries, and rare versus common symbols. Compare the baseline, binding curriculum, identity-copy curriculum, and shuffled-answer curriculum across shakespeare_char, enwik8, and text8, reporting ordinary validation loss, binding accuracy, binding loss by delay and pair count, repeated-target validation loss, train-val gap, total train time, and unchanged inference tokens per second.
