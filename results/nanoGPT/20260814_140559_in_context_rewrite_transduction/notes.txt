# Title: In-Context Rewrite Transduction Curricula for Program-Aware Character Language Models
# Experiment description: Add a get_rewrite_batch(vocab_size, batch_size, block_size, device) helper that creates synthetic auxiliary sequences using only token ids already present in the dataset vocabulary. Each sequence reserves a few frequent tokens as delimiters when possible, writes a compact rule table in the prefix, then writes a query string followed by an answer string produced by deterministic left-to-right longest-match rewriting. Keep the rule system bounded and simple: start with one-token substitutions, then gradually introduce two-token patterns, short insertions, and short deletions while constraining the full sequence to fit block_size + 1. Construct X and Y as usual, but set targets to -1 outside the answer region so the auxiliary loss trains only execution of the in-context rewrite program. In train(), keep ordinary real-text next-character cross-entropy on every iteration; after warmup_iters, every rewrite_interval iterations add one rewrite batch with total_loss = lm_loss + lambda_rewrite * rewrite_loss, ramping lambda_rewrite to 0.05 to 0.15. Evaluation and generation on real text remain unchanged. Extend diagnostics to report ordinary validation loss as the primary metric plus held-out rewrite accuracy by rule type, query length, unseen symbol assignments, and overlapping-rule cases. Compare against the baseline, a copy-only synthetic curriculum, shuffled-rule controls, and random synthetic controls across shakespeare_char, enwik8, and text8. Report best validation loss, train-val gap, repeated-substring validation loss, rewrite accuracy, total train time, and unchanged generation tokens per second.
