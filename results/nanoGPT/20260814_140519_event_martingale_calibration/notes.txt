# Title: Event-Martingale Calibration for Sequentially Reliable Character Language Models
# Experiment description: Keep the GPT architecture, data loader, optimizer, evaluation path, and generation code unchanged. After loading each dataset vocabulary, create fixed random binary event partitions over token ids, balanced by train-set unigram mass, with one event bank for training regularization and a disjoint bank for diagnostics. Add event_martingale_loss(logits, targets, event_matrix, timescales, stake_max): compute softmax probabilities, convert them into event probabilities, and convert targets into realized binary event outcomes. Scan each sequence left to right with no leakage, maintaining detached EMA residuals from previous positions for timescales such as 8, 32, and 128. Convert each past residual EMA into a clipped stake stake_max * tanh(ema / scale), then compute current log-wealth increments log1p(stake * (outcome - probability)). Penalize only positive cumulative normalized log wealth, averaged over events, timescales, and sequences. Train with ordinary next-character cross-entropy every iteration; after warmup_iters and every martingale_interval iterations, add a small ramped lambda_martingale term with values such as 0.001, 0.005, and 0.01. Extend estimate_loss to report ordinary validation NLL as the primary metric, train-event and held-out-event martingale wealth growth, residual autocorrelation by timescale, expected calibration error, Brier score, confidence-bucket validation loss, train-val gap, total train time, and unchanged generation tokens per second. Compare against CE-only training, residual autocorrelation whitening, PIT-independence calibration, shuffled-time residual controls, and random-stake controls across shakespeare_char, enwik8, and text8.
