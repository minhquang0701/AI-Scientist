# Title: Counterfactual Prefix Consistency for Distractor-Robust Autoregressive Language Models
# Experiment description: Add a training-time consistency regularizer for robustness to irrelevant distant context. Keep the standard clean forward pass on X,Y and optimize ordinary next-character cross-entropy. After warmup_iters, create X_cf by rolling X along the batch dimension and replacing the first prefix_len tokens of each sequence with another example's prefix, leaving positions prefix_len onward unchanged. Run a second forward pass on X_cf,Y, ignore its cross-entropy, and compute a temperature-scaled KL loss from detached clean logits to counterfactual-prefix logits only on unchanged suffix positions t >= prefix_len + burn_in. Train with total_loss = clean_ce_loss + alpha_t * temperature^2 * KL(clean || counterfactual), ramping alpha_t from 0 to alpha over 1000 iterations after warmup. Use prefix_len=128, burn_in=16, temperature=2.0, and alpha values 0.05 and 0.1 as main settings, with prefix_len=64 as a small ablation. Keep estimate_loss, best validation loss, final reporting, and generation based on clean full-context next-character loss. Add validation probes that perform the same prefix swap on validation batches and report suffix-only distractor-prefix loss, clean-to-counterfactual KL, and the robustness gap relative to clean validation. Compare against the baseline across shakespeare_char, enwik8, and text8 using clean best validation loss, distractor-prefix robustness, convergence speed, total train time, inference tokens per second, and generated samples.
