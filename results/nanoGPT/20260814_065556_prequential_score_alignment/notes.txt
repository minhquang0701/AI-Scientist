# Title: Prequential Score Alignment for Predictive-State Updates in Character Transformers
# Experiment description: Modify GPT.forward() to optionally return final hidden states after ln_f while keeping evaluation and generation unchanged. Add a prequential_score_alignment_loss(hidden, logits, idx, embedding_weight, burnin=8, max_positions=1024) helper. For positions t > 0, use detached logits at t-1 to compute p_prev, the model prediction for the newly observed token idx[:, t]. Form the detached hidden-space Fisher score target score_t = embedding_weight[idx[:, t]] - p_prev @ embedding_weight, using the tied embedding matrix. Compute the adjacent hidden update delta_t = hidden[:, t] - hidden[:, t-1], optionally remove batch means, normalize both vectors, and apply a conservative cosine hinge loss such as relu(margin - cosine) on a random subsample of valid positions. Optionally gate out extremely high-surprisal positions so rare shocks are not overconstrained. Train every iteration with ordinary next-character cross-entropy; after warmup_iters and every score_interval iterations, add lambda_score times this loss with values such as 0.005, 0.01, and 0.02. Extend estimate_loss() to report ordinary train and validation loss as the primary metric, score-alignment cosine, negative-alignment rate, expected calibration error, train-val gap, total train time, and unchanged generation tokens per second. Compare against the baseline, hidden-smoothing control, shuffled-observed-token score control, and norm-only update regularizer across shakespeare_char, enwik8, and text8.
