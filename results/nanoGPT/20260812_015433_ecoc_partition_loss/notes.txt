# Title: Error-Correcting Partition Losses for Dense Character-Level Supervision
# Experiment description: Keep the GPT architecture, data loader, evaluation loop, and generation code unchanged. After loading each dataset's vocab_size, create a fixed deterministic balanced binary codebook C of shape vocab_size by code_dim, with entries in {-1, 1} and code_dim values such as 16, 32, and 64. In the training loop, compute the ordinary next-character cross-entropy from logits as the primary loss. After warmup_iters, compute probs = softmax(logits), then for each code bit compute the model probability mass assigned to the target token's side of that binary partition. Add a ramped auxiliary binary cross-entropy loss that encourages high probability mass on the correct side of each partition, with lambda_code values such as 0.02, 0.05, and 0.1. This provides dense output supervision without adding parameters or changing inference. Extend estimate_loss() to report ordinary train/validation loss as the primary metric, partition loss, expected calibration error, rare-token validation loss, and generated character-frequency KL. Compare against the baseline, uniform label smoothing, shuffled-code partitions, and random normalized token-weighting controls across shakespeare_char, enwik8, and text8.
