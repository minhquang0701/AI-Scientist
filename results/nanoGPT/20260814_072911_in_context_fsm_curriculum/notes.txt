# Title: In-Context Finite-State Transduction Curricula for State-Aware Character Language Models
# Experiment description: Add a get_fsm_batch(vocab_size, batch_size, block_size, device) helper that generates synthetic auxiliary windows using only token ids from the current dataset vocabulary. For each sequence, reserve a few marker ids and randomly choose disjoint ids to serve as state symbols and input symbols. Sample a small deterministic finite-state machine, encode its transition table in the prefix as repeated triples current_state, input_symbol, next_state, then emit a start state followed by an input-symbol stream. Insert sparse query markers whose following token is the current latent state after applying the encoded transition rules to all previous inputs. Construct X and Y normally, but set Y to -1 everywhere except query-answer positions so the auxiliary objective isolates rule induction and state tracking. In train(), keep ordinary real-text next-character cross-entropy on every iteration; after warmup_iters, every fsm_interval iterations, add one FSM auxiliary batch with total_loss = lm_loss + lambda_fsm * fsm_loss, ramping lambda_fsm to 0.05 to 0.15. Automatically shrink the number of states or input symbols for small vocabularies. Extend diagnostics to report ordinary validation loss as the primary metric, held-out FSM query accuracy by rollout length and number of states, accuracy on unseen token-role assignments and unseen transition tables, train-val gap, total train time, and unchanged generation tokens per second. Compare the baseline, FSM curriculum, one-step transition lookup control, shuffled-transition-table control, and compute-matched random synthetic control across shakespeare_char, enwik8, and text8.
