# Title: Causal Novelty Key Biases for Redundancy-Aware Transformer Memory
# Experiment description: Extend GPTConfig with use_novelty_key_bias, novelty_window, novelty_support_tau, novelty_bias_max, novelty_gate_init, and novelty_random_control. Modify CausalSelfAttention.forward so enabled models use the manual causal attention path. For each layer, compute detached L2-normalized representations from the layer input x, then build a leakage-free key novelty score for each position by comparing it only to earlier positions within novelty_window: novelty_t = 0.5 * (1 - max_previous_cosine), with novelty_t set to 0 when no previous positions are available. Shrink novelty toward zero when few previous positions are available using support / (support + novelty_support_tau), and clamp it to [0, 1] without any future-dependent sequence normalization. Add a learned bounded per-head scalar times the key novelty score to attention logits before the causal softmax, with all gates initialized to zero so the model starts as a manual-attention baseline. Keep the data loader, optimizer, next-character cross-entropy objective, evaluation loop, and generation procedure unchanged, recomputing novelty from the visible context during generation. Compare the flash-attention baseline, manual-attention zero-bias control, causal novelty key bias, randomly permuted novelty scores, and a simple token-frequency novelty control across shakespeare_char, enwik8, and text8. Report ordinary validation loss, train-val gap, validation loss at context lengths 64/128/256, repeated-target versus novel-target loss, loss by previous-occurrence distance bucket, learned novelty gates by layer and head, attention mass assigned to high-novelty keys, novelty-score statistics, total train time, and inference tokens per second.
