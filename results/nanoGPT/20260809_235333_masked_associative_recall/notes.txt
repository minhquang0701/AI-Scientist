# Title: Masked Associative Recall Augmentation for In-Context Binding in Character Language Models
# Experiment description: Add a training-only auxiliary associative-recall task using only token IDs from the current dataset vocabulary. Implement make_associative_recall_batch(data, vocab_size, block_size, batch_size, num_pairs, key_len, value_len, filler_len) that builds fixed-layout sequences containing several key-value records, distracting filler sampled from train.bin, and later key queries followed by their associated values. Construct recall targets with -1 everywhere except positions where the model must predict the value tokens after a query key, reusing the existing cross_entropy ignore_index behavior. In the training loop, keep the ordinary text batch and next-character loss as the primary objective. After warmup_iters, with probability recall_prob run one auxiliary recall batch and optimize total_loss = lm_loss + alpha_t * recall_loss, ramping alpha_t after warmup. Keep ordinary validation, generation, final reporting, and inference speed unchanged. Add a no-gradient recall evaluation varying num_pairs, key_len, value_len, filler distance, and distractor keys, reporting masked recall loss and exact full-value recovery accuracy. Compare against the baseline across shakespeare_char, enwik8, and text8 using best natural validation loss, convergence speed, total train time, inference tokens per second, generated samples, and associative recall accuracy. Main setting: num_pairs=8, key_len=3, value_len=4, recall_prob=0.1, alpha=0.2, with small ablations alpha=0.1 and recall_prob=0.05.
