# Experiment description: Modify GPT.forward to optionally return final hidden states after ln_f while preserving the standard logits and next-character cross-entropy behavior. Keep estimate_loss, best validation loss, final reporting, generation, and inference speed based only on the ordinary lm_head. Add diagnostics for deterministic bottleneck validation loss using mu, KL per token, active latent dimensions, train-validation gap, and calibration by confidence bucket.
