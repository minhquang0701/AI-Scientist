# Title: Causal Haar Context Adapters for Multi-Scale Character Language Modeling
# Experiment description: Add an optional CausalHaarContextAdapter inside each transformer Block after the attention residual and before the MLP. The adapter applies LayerNorm, projects hidden states to a bottleneck dimension such as n_embd // 4, computes edge-corrected leakage-free causal moving averages over dyadic windows such as 2, 4, 8, 16, 32, and 64 using cumulative sums, forms Haar-like detail bands by subtracting adjacent scale averages, mixes the bands with learned per-scale weights, projects back to n_embd, applies dropout, and adds the result through a small nonzero learned residual gate. Extend GPTConfig with use_haar_context_adapter, haar_windows, haar_bottleneck_mult, haar_gate_init, and haar_dropout. Keep the ordinary next-character cross-entropy objective, optimizer, batching, evaluation loop, and generation procedure unchanged. Compare the baseline, causal Haar adapters, a low-pass-only causal average adapter, and a same-parameter feedforward adapter across shakespeare_char, enwik8, and text8. Report best validation loss, final train loss, train-val gap, validation loss at context lengths 64, 128, and 256, repeated-target versus novel-target loss, learned residual gates, learned scale weights by layer, parameter count, total train time, and inference tokens per second.
