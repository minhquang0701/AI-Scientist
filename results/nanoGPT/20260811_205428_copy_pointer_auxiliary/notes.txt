# Title: Causal Copy-Pointer Auxiliary Supervision for Character Language Models
# Experiment description: Modify GPT.forward() to optionally return final hidden states after ln_f. Add an optional lightweight copy-pointer head to GPT with query and key projections from hidden states plus one learned null key. Keep the ordinary next-token cross-entropy as the main objective. After warmup_iters, every pointer_interval iterations such as 4 or 8, compute pointer labels for a subsampled set of batch positions: for prediction position t, the target is the most recent prefix position p <= t where X[:, p] equals Y[:, t], or a null class if the target character has not appeared in the visible prefix. Score all causal prefix positions with q_t dot k_p, mask invalid future positions, append the null logit, and compute cross-entropy pointer loss. Use a balanced subsample of copyable and null positions, capped at about 512 positions per auxiliary step, and optimize total_loss = lm_loss + lambda_pointer * pointer_loss with lambda_pointer ramped from 0.0 to 0.05 or 0.1 after warmup. Evaluation and generation use the normal lm_head only. Extend estimate_loss() to report ordinary train/validation loss, pointer accuracy, null accuracy, validation loss on copyable versus novel targets, and validation loss by copy distance bucket. Compare against the baseline and a small parameter-matched control across shakespeare_char, enwik8, and text8 using best ordinary validation loss as the primary metric, with copy-distance robustness, convergence speed, total train time, and unchanged inference tokens per second as secondary metrics.
