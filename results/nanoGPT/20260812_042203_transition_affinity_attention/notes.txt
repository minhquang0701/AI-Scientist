# Title: Transition-Affinity Attention Biases for Tokenizer-Free Language Models
# Experiment description: Before training each dataset, scan train.bin once to compute smoothed predecessor and successor distributions for every character token. Concatenate each token's predecessor distribution, successor distribution, and normalized log frequency into a transition fingerprint, L2-normalize the fingerprints, compute a vocab-by-vocab cosine affinity matrix, clamp negative affinities to zero, and keep only the top-k neighbors per token. Extend GPTConfig with use_transition_affinity_attention, affinity_topk, affinity_bias_max, and affinity_bias_init. Register the fixed affinity matrix as a non-trainable buffer in GPT, pass idx through GPT.forward into each Block and CausalSelfAttention, and when enabled use the manual attention path with an added logit bias scale_h * affinity[idx_query, idx_key] for each head, where scale_h = affinity_bias_max * tanh(raw_scale_h). Initialize raw_scale_h to 0.0 so the model starts as a manual-attention baseline. Keep the ordinary next-character cross-entropy objective, optimizer, batching, evaluation loop, and generation API unchanged. Compare the original flash-attention baseline, manual-attention zero-bias control, transition-affinity attention, shuffled-affinity control, and identity-only attention bias across shakespeare_char, enwik8, and text8. Report best validation loss, final train loss, train-val gap, validation loss on repeated versus novel targets, validation loss by previous-occurrence distance, learned affinity scales by layer and head, attention mass on high-affinity prior positions, total train time, and inference tokens per second.
