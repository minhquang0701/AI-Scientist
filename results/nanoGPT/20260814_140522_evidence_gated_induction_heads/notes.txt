# Title: Evidence-Gated Induction Head Supervision for Character Language Models
# Experiment description: Modify CausalSelfAttention.forward, Block.forward, and GPT.forward to optionally return attention probabilities on scheduled auxiliary iterations, using the manual attention path only when attention maps are requested and preserving the default flash-attention path for ordinary training, evaluation, and generation. Add compute_induction_evidence_targets(X, Y, suffix_lengths=[2,4,8]) that finds earlier suffix matches ending at p < t, marks the visible successor key p+1 only when p+1 < t, and treats it as a positive induction target only if X[:, p+1] equals the supervised next token Y[:, t]. Build a normalized target distribution over positive successor keys, weighted by suffix length and recency, and skip positions with no positive evidence while logging conflicting matches as diagnostics. Train every iteration with ordinary next-character cross-entropy. After warmup_iters and every induction_interval iterations, request attention maps from selected middle and late layers and add a small ramped auxiliary loss equal to the negative log attention mass on the positive induction targets, using a max-over-heads or soft-min competition so only naturally useful heads receive strong pressure. Extend estimate_loss to report ordinary validation loss, repeated-suffix validation loss, novel-context validation loss, induction-evidence coverage, conflict rate, attention mass on positive induction successors, and number of specialized induction heads. Compare against the baseline, ungated induction-target supervision, shuffled-successor-target control, and recent-token attention control across shakespeare_char, enwik8, and text8. Generation remains unchanged.
