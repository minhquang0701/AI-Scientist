# Title: Adjacent Swap Consistency for Order-Robust Residual Transformers
# Experiment description: Modify GPT.forward() to accept an optional swap_pair argument. When swap_pair=(i, i+1), apply all transformer blocks in the usual order except that the selected adjacent pair is applied in reverse order; when swap_pair is None, keep the existing path unchanged. Train every iteration with the ordinary next-character cross-entropy from the standard block order. After warmup_iters, every swap_interval iterations, sample one adjacent layer pair and run an auxiliary deterministic comparison with dropout disabled: compute detached clean logits from the standard order, compute swapped-order logits with gradients enabled, and add a small ramped auxiliary loss combining swapped cross-entropy with temperature-2 KL consistency from clean logits to swapped logits. Use conservative lambda_swap values such as 0.01, 0.05, and 0.1 so the normal ordered model remains primary. Evaluation and generation use the original block order unchanged. Extend estimate_loss() to report ordinary train and validation loss, swapped-order validation loss for each adjacent pair, clean-to-swapped KL, adjacent-swap degradation, train-val gap, total train time, and inference tokens per second. Compare against the baseline and a compute-matched extra-forward control without the swap-consistency KL across shakespeare_char, enwik8, and text8.
