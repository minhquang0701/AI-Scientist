# Title: Uniform-Exposure Causal Attention for Sink-Resistant Character Transformers
# Experiment description: Add GPTConfig fields use_uniform_exposure_attention, exposure_gamma, exposure_correction_strength, and exposure_eps. In CausalSelfAttention.forward, when enabled, use the manual causal attention path. Compute ordinary masked causal attention logits and softmax probabilities. Estimate detached key load by summing attention probabilities over query positions for each batch, head, and key. Precompute a row-uniform causal exposure target where each query distributes one unit of mass uniformly over all visible keys, then optionally sharpen or flatten it with exposure_gamma and renormalize so total target load equals the number of query positions. Add a detached correction exposure_correction_strength * log((target_load + eps) / (key_load + eps)) to each key's logits, apply a final masked softmax, and use the corrected attention to aggregate values. Keep the GPT architecture, optimizer, data loader, ordinary next-character cross-entropy objective, evaluation, and generation otherwise unchanged. Compare the flash-attention baseline, a manual-softmax control, and uniform-exposure attention with gamma values such as 0.5 and 1.0 and correction strengths such as 0.25, 0.5, and 1.0. Extend diagnostics to report ordinary train and validation loss, validation loss at context lengths 64/128/256, exposure-normalized key-load ratio, attention mass on early crop-boundary tokens, attention entropy, repeated-target versus novel-target validation loss, total train time, and inference tokens per second across shakespeare_char, enwik8, and text8.
