# Title: Target-Masked Lookahead Distillation for Causal Character Language Models
# Experiment description: Add a learned mask_embedding to GPT and modify GPT.forward to accept input_mask, replacing masked token embeddings before positional embeddings. Modify CausalSelfAttention.forward to accept lookahead_tokens, defaulting to 0 for the existing causal path; when lookahead_tokens > 0, use a manual mask that permits each position to attend to its causal prefix plus a bounded future window. Train every iteration with ordinary strictly causal next-character cross-entropy. After warmup_iters and every lookahead_interval iterations, sample a sparse nonadjacent set of prediction anchor positions t, create a teacher input where X[:, t + 1] is replaced by mask_embedding, and run one target-masked lookahead forward with lookahead sampled from values such as 4, 8, and 16. Add a small ramped auxiliary loss on only the anchor positions: weak cloze-lookahead CE plus temperature-2 KL from detached lookahead logits to the ordinary causal logits. Keep validation and generation strictly causal by default. Extend estimate_loss to report causal validation loss, target-masked lookahead loss, causal-lookahead KL, and validation loss by predictive-entropy or cloze-gain bucket. Compare against the baseline, target-masked causal auxiliary training without lookahead, unmasked lookahead as a leakage diagnostic excluded from main claims, and reverse-direction distillation across shakespeare_char, enwik8, and text8.
