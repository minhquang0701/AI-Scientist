# Title: Evidence-Calibrated Distillation for Short-Context Robust Language Models
# Experiment description: Keep the GPT architecture, data loader, optimizer, ordinary full-context next-token cross-entropy, evaluation path, and default generation unchanged. In the training loop, compute the standard full-context logits and loss on every iteration. After warmup_iters, every distill_interval iterations, take a fixed limited-context suffix of the same batch, for example X_short = X[:, -64:] and Y_short = Y[:, -64:], and run one extra forward pass. Align full-context logits to the same suffix positions. Using detached logits, compute unreduced target losses for both views and define evidence_gain = clamp(short_ce - full_ce, min=0). Convert this to a bounded gate, such as gate = clamp(evidence_gain / gain_scale, 0, 1). Add a ramped auxiliary loss: gate-weighted temperature-2 KL from detached full-context logits to short-context logits, plus a low-gate overconfidence penalty (1 - gate) * relu(full_entropy - short_entropy)^2. On non-distillation iterations, train exactly like the baseline. Extend estimate_loss to report ordinary train and validation loss as the primary metric, validation loss at context lengths 32, 64, 128, and 256, expected calibration error at each context length, mean evidence gain, and short-context overconfidence gap. Compare against the baseline, ungated short-context distillation, and entropy-only regularization across shakespeare_char, enwik8, and text8 using best full-context validation loss, short-context degradation, calibration, total train time, and unchanged generation tokens per second.
