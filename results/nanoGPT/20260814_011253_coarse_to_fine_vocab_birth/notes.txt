# Title: Coarse-to-Fine Vocabulary Birth for Tokenizer-Free Language Modeling
# Experiment description: Before training each dataset, scan train.bin to compute smoothed predecessor counts, successor counts, and token frequencies for every character id. Build transition fingerprints by concatenating normalized predecessor counts, successor counts, and log frequency, then cluster characters into a coarse alphabet with K clusters such as 8, 16, or min(32, vocab_size) using deterministic numpy k-means. Add a get_batch() option that remaps X and Y through token_to_cluster so a standard GPT can be trained with vocab_size=K on the coarse stream. Train this coarse GPT for an initial fraction of the total budget, for example 20% of max_iters. Then instantiate a full character-vocabulary GPT with the same transformer dimensions, copy shared non-vocabulary parameters from the coarse model, and initialize each character embedding/output row from its cluster embedding plus small variance-matched token-specific noise. Rebuild AdamW and continue ordinary character-level next-token training for the remaining budget. During a short recovery window, optionally add a decaying cluster anchor loss by logsumexp-aggregating full character logits into cluster logits and applying cluster cross-entropy. Compare against the standard character GPT, frequency-cluster birth, random balanced-cluster birth, no-anchor birth, and a compute-matched character-only baseline. Report best character validation loss, validation loss per wall-clock time, loss spike after expansion, rare versus common token loss, repeated versus novel target loss, train-val gap, total train time, and unchanged final-model inference tokens per second.
