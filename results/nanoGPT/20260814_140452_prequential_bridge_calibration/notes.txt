# Title: Prequential Bridge Calibration for Drift-Controlled Character Language Models
# Experiment description: Keep the GPT architecture, data loader, optimizer, evaluation path, and generation code unchanged. Add a prequential_bridge_calibration_loss(logits, targets, chunk_len=64, huber_delta=0.05) helper. From softmax(logits), build residuals probs - one_hot(target) with ignore_index support, split each sequence into non-overlapping chunks, and compute cumulative residual paths over time for each vocabulary token. For each chunk, subtract the straight-line bridge from zero to the final cumulative residual, so the loss focuses on within-chunk temporal drift rather than endpoint marginal mismatch. Apply a Huber or squared penalty to the bridge residuals, normalized by the number of valid positions and vocabulary size. Train with ordinary next-character cross-entropy on every iteration; after warmup_iters and every bridge_interval iterations, add a small ramped lambda_bridge times this loss, sweeping values such as 0.005, 0.01, and 0.05. Extend estimate_loss to report ordinary train and validation NLL as the primary metric, bridge calibration error, endpoint chunk-marginal error, prefix residual drift curves, expected calibration error, generated character-frequency KL, repeated-character rate, distinct n-gram fraction, train-val gap, total train time, and unchanged inference tokens per second. Compare against the CE-only baseline, local marginal calibration, temporal spectral calibration, and a shuffled-time target control across shakespeare_char, enwik8, and text8.
