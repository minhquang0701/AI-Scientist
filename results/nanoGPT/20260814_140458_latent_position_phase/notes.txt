# Title: Latent Position-Phase Marginalization for Crop-Robust Character Transformers
# Experiment description: Separate supervised sequence length from positional capacity by keeping train_seq_len=256 while setting the learned positional table capacity to 512. Modify GPT.forward(idx, targets=None, position_ids=None) so the default path uses ordinary positions 0..T-1 and generation remains unchanged, while optional position_ids can shift the same token window to different absolute position phases. Train normally with offset-0 next-character cross-entropy on every iteration. After warmup_iters and every phase_interval iterations, run the same X,Y batch under a small fixed offset set such as [0, 32, 64, 128]. On an early boundary band such as the first 128 target positions, gather true-target log probabilities from each phase view and add a low-weight auxiliary loss equal to the negative log-mean-exp over phases. Optionally distill the posterior-weighted phase-mixture logits back into the default offset-0 logits on the same band with a small temperature-2 KL term. Extend estimate_loss to report ordinary offset-0 validation loss, phase-marginal validation loss, validation loss variance across position phases, boundary versus interior validation loss, phase posterior entropy, and offset-sensitivity KL. Compare the original baseline, a larger-position-table baseline, random position-offset training, pairwise offset-consistency KL, and latent position-phase marginalization across shakespeare_char, enwik8, and text8.
