# Title: Ordered Prefix-State Supervision for Causal Character Language Models
# Experiment description: After loading each dataset vocabulary, create a small fixed set of coarse finite-state sketches. For each sketch, assign token ids to 4 or 8 balanced event groups, and assign each group a random permutation over 16 or 32 automaton states. Scanning X left to right gives an ordered causal state label at each position after consuming X[:, :t+1]. Modify GPT.forward() to optionally return final hidden states after ln_f, and add small training-only state heads, one Linear(n_embd, num_states) per sketch. Train with ordinary next-character cross-entropy on every iteration; after warmup_iters, every state_interval iterations, add a ramped auxiliary cross-entropy from the state heads to the finite-state labels, with lambda_state capped around 0.02 to 0.10. Evaluation and generation ignore the state heads and use the standard lm_head. Extend estimate_loss() to report ordinary train/validation loss, ordered-state accuracy, validation loss at context lengths 64 and 256, repeated-target versus novel-target loss, train-val gap, total train time, and unchanged generation tokens per second. Compare against the baseline, shuffled-state-label controls, detached-hidden probes, and a commutative prefix-sketch control with matched label entropy to test whether order-sensitive causal state supervision improves language modeling beyond generic auxiliary prediction.
