# Title: Input-Output Role Surgery for Tied Character Embeddings
# Experiment description: Keep the GPT architecture, data loader, ordinary next-character cross-entropy objective, evaluation, and generation unchanged. Add a logits_from_hidden helper and optional GPT.forward flags detach_input_embedding and detach_output_embedding, so the tied embedding matrix can be used only as an input embedding or only as an output classifier in diagnostic forwards. During normal iterations, train exactly as the baseline. After warmup_iters and every role_surgery_interval iterations, run the ordinary forward and backward pass as usual. After GradScaler unscaling and before gradient clipping, compute two additional autograd.grad probes on the same batch only for transformer.wte.weight: an input-role gradient from a forward pass with the output classifier weight detached, and an output-role gradient from a forward pass with input embeddings detached. Cast the two gradients to float32, measure their global cosine agreement, and if the cosine is negative replace the tied embedding gradient with a PCGrad-style projected combination, rescaled to match the original embedding-gradient norm. If the cosine is nonnegative, leave the ordinary embedding gradient unchanged or use a conservative averaged blend as an ablation. Leave all other parameter gradients from the ordinary CE pass unchanged. Disable torch.compile for this experiment if needed to keep gradient replacement reliable. Extend logging and estimate_loss to report ordinary train and validation loss, input-output gradient cosine, projection frequency, row-wise conflict diagnostics, embedding update norm, rare versus common token validation loss, repeated versus novel target loss, expected calibration error, train-val gap, total train time, and unchanged inference tokens per second. Compare the baseline, tied-embedding role surgery, a no-projection extra-gradient control, a random-gradient projection control, and an untied-output diagnostic across shakespeare_char, enwik8, and text8.
