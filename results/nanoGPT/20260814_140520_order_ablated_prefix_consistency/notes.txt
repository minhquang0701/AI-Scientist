# Title: Order-Ablated Prefix Consistency for Context-Robust Character Language Modeling
# Experiment description: Add make_order_ablated_prefix_view(X, protected_suffix_len, chunk_len) that preserves the final protected suffix exactly, partitions the older prefix into fixed-size chunks such as 8 or 16 tokens, and randomly permutes those chunks within each sequence. This keeps sequence length, absolute positions, and the exact older-prefix token multiset unchanged while disrupting long-range order but preserving short local fragments. Train every iteration with ordinary clean next-character cross-entropy. After warmup_iters and every order_interval iterations, run one auxiliary forward pass on the order-ablated view and add a small ramped temperature-2 KL loss from detached clean logits to ablated logits only on the protected suffix after a short burn-in such as 16 tokens. Gate the KL by detached target-loss degradation, using little or no consistency pressure where the ablated prefix is much worse than the clean prefix, so genuinely useful ordered context is not suppressed. Extend estimate_loss to report clean validation loss, order-ablated validation loss, clean-to-ablated degradation, suffix KL, active gate fraction, loss by previous-occurrence distance, and repeated-target versus novel-target loss. Compare the baseline, chunk-order consistency, full-prefix token shuffle as a stronger ablation, random prefix replacement, and an ungated consistency control across shakespeare_char, enwik8, and text8. Generation remains unchanged.
