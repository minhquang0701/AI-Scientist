Modify GPT.forward(idx, targets=None, prefix_state=None, return_hidden=False) so the default path is unchanged; when prefix_state is supplied, add gate * state_condition_proj(prefix_state) to token embeddings before positional embeddings. After warmup_iters, every monoid_interval iterations, sample contiguous chunks A, B, and C with chunk_len such that A+B+C fits in the block. Train composer(s_A, s_B) to match the direct state of A+B, and composer(s_B, s_C) to match B+C. Compare baseline GPT, state conditioning without composition, predictive state monoids, and shuffled-chunk composition controls across shakespeare_char, enwik8, and text8.
