# Title: Signed Innovation Feedback for Predictive-Coding Character Language Models
# Experiment description: Modify GPT.forward() to optionally accept innovation_values with shape batch by time by innovation_dim. Add a fixed normalized random projection matrix R from vocab_size to innovation_dim, an innovation_proj Linear(innovation_dim, n_embd), and a learned scalar gate initialized to zero. When innovation_values are provided, add gate * innovation_proj(innovation_values) to token embeddings before positional embeddings; when absent, the model is exactly the baseline. In train(), always compute the ordinary clean next-character cross-entropy. After warmup_iters and every innovation_interval iterations, construct causal signed innovations from the clean forward pass: innovation[:, 0] = 0 and innovation[:, t] = detach(R[X[:, t]] - softmax(clean_logits[:, t - 1]) @ R) for t >= 1, with optional clipping or RMS normalization. Run one second feedback-conditioned forward pass on the same X,Y and add a small ramped auxiliary feedback CE loss plus an optional temperature-2 KL anchor to the clean logits. Extend estimate_loss() to report clean validation loss as the primary metric, feedback-conditioned validation loss, clean-to-feedback KL, loss by observed-surprisal bucket, expected calibration error, learned gate value, total train time, and ordinary generation tokens per second. Compare the baseline, signed innovation feedback, scalar surprisal feedback, shuffled innovation feedback, and zero-gate controls across shakespeare_char, enwik8, and text8. Default generation remains unchanged, with an optional diagnostic generation mode that updates innovations after sampled tokens.
