# Title: Bigram Information-Time Position Embeddings for Character Language Models
# Experiment description: Before training each dataset, scan train.bin once to compute additively smoothed unigram probabilities and a smoothed bigram transition matrix P(x_t | x_{t-1}), plus the mean train-set bigram surprisal for normalization. Extend GPTConfig with use_information_positions, info_pos_capacity, info_pos_gate_init, and use_absolute_positions. In GPT.__init__, add an optional info_wpe embedding table and one learned scalar gate initialized to zero, and register the frozen unigram and bigram log probabilities as buffers. Add compute_information_positions(idx): set info_pos[:, 0] = 0, then for t > 0 add normalized causal surprisal -log P(idx[:, t] | idx[:, t - 1]) / mean_surprisal to the previous coordinate, round to integer ids, and clamp to info_pos_capacity - 1. Modify GPT.forward so enabled models add gate * info_wpe(info_position_ids) to the usual token embeddings and, when use_absolute_positions is true, the usual absolute position embeddings. The disabled path is unchanged. Generation automatically recomputes information positions from the visible context inside forward. Keep the next-character cross-entropy objective, optimizer, batching, evaluation, and sampling otherwise unchanged. Compare the baseline, gated bigram information positions, information positions without absolute positions, unigram-surprisal positions, and shuffled-increment controls across shakespeare_char, enwik8, and text8. Report ordinary validation loss, validation loss at context lengths 64, 128, and 256, loss by low/high bigram-surprisal bucket, loss by absolute-position bucket, learned gate value, average information-clock speed, train-val gap, total train time, and inference tokens per second.
