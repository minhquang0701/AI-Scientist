# Title: Influence-Gated Context Masking for Causal Language Model Robustness
# Experiment description: Add a learned mask_embedding to GPT and modify GPT.forward(idx, targets=None, input_mask=None) so masked input positions replace token embeddings before positional embeddings, while the default path remains unchanged. In train(), always compute the ordinary clean next-character cross-entropy and clean logits. After warmup_iters, every influence_interval iterations, sample one older-prefix token position per sequence from logarithmic distance buckets while protecting a recent suffix such as the final 96 or 128 tokens. Run one additional masked forward on the same batch. Compute detached counterfactual influence for each sequence as the increase in average protected-suffix true-target NLL under the masked forward relative to the clean forward. Convert influence into a bounded low-influence gate, for example gate = exp(-influence / tau), and add a small ramped auxiliary temperature-2 KL consistency loss from detached clean suffix logits to masked suffix logits, weighted by this gate. High-influence deletions receive little invariance pressure, while low-influence deletions are encouraged to leave predictions unchanged. Extend estimate_loss() to report ordinary validation loss, validation loss under random older-prefix masking, mean counterfactual influence, clean-to-masked KL, low-influence robustness, high-influence sensitivity, train-val gap, total train time, and unchanged clean generation tokens per second. Compare against the baseline, random context masking with the same mask rate, and ungated masked consistency across shakespeare_char, enwik8, and text8.
