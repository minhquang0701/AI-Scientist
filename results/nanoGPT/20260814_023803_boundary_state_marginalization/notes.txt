# Title: Boundary-State Marginalization for Crop-Uncertain Character Language Modeling
# Experiment description: Extend GPTConfig with use_boundary_state_marginalization, num_boundary_states, num_boundary_tokens, boundary_band_len, boundary_prior_init, boundary_gate_init, boundary_interval, and lambda_boundary_max. Add learned boundary prefix embeddings of shape num_boundary_states by num_boundary_tokens by n_embd and learned global prior logits over boundary states. Modify GPT.forward to support an optional boundary_state_id path that prepends the selected boundary tokens before the real token embeddings, discards prefix logits, keeps real-token targets aligned, and computes logits only for real positions. Keep the default idx-only forward, validation, and generation paths unchanged. In train(), always optimize the ordinary next-character cross-entropy on the normal no-prefix path. After warmup_iters and every boundary_interval iterations, expand the current batch over all boundary states, run one batched boundary-prefix forward pass, gather true-target log probabilities for the first boundary_band_len real positions, and compute an exact latent-state marginal NLL using logsumexp over learned prior log probabilities plus per-state boundary-band log likelihoods. Add this loss with a ramped lambda_boundary while retaining ordinary CE as the dominant objective. Extend estimate_loss to report ordinary validation loss, boundary-marginal validation loss, best single-boundary-state validation loss, validation loss by absolute position bucket, boundary-to-interior loss gap, learned boundary-state prior entropy, posterior state usage, train-val gap, total train time, and ordinary no-prefix generation tokens per second. Compare against the baseline, one fixed learned virtual prefix, multiple prefix states trained by random state sampling without marginalization, and a shuffled-prior control across shakespeare_char, enwik8, and text8.
