# Title: Amortized Candidate Lookahead Values for Character Language Models
# Experiment description: Modify GPT.forward() to optionally return final hidden states after ln_f. Add a small training-only CandidateValueHead that takes concat(h_t, e_c, h_t * e_c), where h_t is the hidden state at a prediction position and e_c is the detached embedding of a candidate next token, and predicts a scalar short-horizon future cost. Train every iteration with ordinary next-character cross-entropy. After warmup_iters and every value_interval iterations, select a small subbatch, sample one shared anchor position with room for a horizon H such as 8 or 16, and take the top-k candidate tokens from detached clean logits at that anchor while always including the true next token. For each candidate, create a counterfactual teacher-forced copy where X[:, anchor + 1] is replaced by that candidate while later ground-truth inputs remain unchanged. Run these counterfactual copies under torch.no_grad() and define the target value as the average future NLL over predictions anchor + 1 through anchor + H. Normalize target values within each anchor candidate set and train the value head with MSE using a small ramped weight so CE remains dominant. Compare baseline GPT, value-head training with gradients into the trunk, detached-hidden value-probe control, shuffled-value-target control, and optional value-reranked generation that adjusts only top-k final-token logits by subtracting gamma times the predicted value. Report ordinary validation loss as the primary metric, value prediction rank correlation, top-k reranking accuracy, future counterfactual NLL, calibration, generation repetition diagnostics, total train time, and unchanged base generation tokens per second across shakespeare_char, enwik8, and text8.
