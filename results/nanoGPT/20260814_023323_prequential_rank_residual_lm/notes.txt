# Title: Prequential Rank-Residual Language Modeling for Causal Compression-Aware Transformers
# Experiment description: Add a PriorRankCodec that transforms each raw character chunk into a causally invertible rank stream. Before training each dataset, compute a smoothed train-set unigram prior for initialization and smoothing. For raw token x_t, compute a vocabulary ordering using only the already decoded prefix x_<t: mix the unigram prior with recent in-window character counts and in-window bigram transition counts from x_{t-1} when available, then sort tokens by this causal score with deterministic tie-breaking. Encode x_t as its rank in that ordering. Modify get_batch() to sample block_size + 1 raw chunks, encode full chunks into rank chunks, and train the unchanged GPT on X_rank and Y_rank with the same vocab_size. Because the rank transform is one-to-one given the previous ranks, rank-space NLL is an exact character-stream NLL under the transformed model. Modify evaluation to report exact validation NLL, prior-only NLL, loss by prior-rank bucket, residual-rank entropy, repeated-target versus novel-target loss, and train-val gap. Modify generation to maintain decoded raw context alongside generated ranks: sample the next rank from GPT, invert it through the current causal ordering, append the decoded character, and continue. Compare raw character GPT, static frequency-rank remapping, causal move-to-front rank remapping, prequential rank-residual GPT, and additive local-prior logit fusion across shakespeare_char, enwik8, and text8. Report best validation loss, convergence speed, total train time, decoded-character generation speed, and sample quality.
