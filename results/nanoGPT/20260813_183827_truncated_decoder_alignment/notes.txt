# Title: Truncated Decoder Alignment for Sampling-Robust Character Language Models
# Experiment description: Keep the GPT architecture, data loader, optimizer, default evaluation path, and generation code unchanged. Add a truncated_decoder_alignment_loss(logits, targets, keep_frac, temperature, margin) helper. It computes k = max(4, ceil(keep_frac * vocab_size)), builds a detached top-k candidate set from logits divided by temperature, computes conditional target NLL over the top-k-renormalized distribution when the true target is inside the retained set, and adds a bounded softplus margin penalty when the target is outside the set by encouraging its logit to exceed the kth retained logit by a small margin. Train with ordinary full-softmax next-character cross-entropy on every iteration; after warmup_iters and every decoder_interval iterations, add a small ramped auxiliary alignment loss with keep_frac values such as 0.25, 0.5, and 0.8 and temperatures such as 0.8, 1.0, and 1.2. Extend estimate_loss to report ordinary validation NLL as the primary metric, target-in-retained-set coverage, truncated conditional NLL, excluded-target margin rate, expected calibration error, repeated n-gram rate, distinct n-gram fraction, and generation tokens per second under matching truncation settings. Compare the baseline, truncated decoder alignment, temperature-only alignment, uniform label smoothing, and a compute-matched extra-CE control across shakespeare_char, enwik8, and text8.
