# Title: Stop-Gradient Soft Rollout Matching for Sequence-Level Character Language Modeling
# Experiment description: Modify GPT.forward to optionally accept inputs_embeds while preserving the default idx path for ordinary training, evaluation, and generation. Add a rollout_moment_loss helper used only on scheduled auxiliary iterations. In train(), keep standard next-character cross-entropy on every iteration. After warmup_iters and every rollout_interval iterations, reconstruct the contiguous batch chunk as torch.cat([X[:, :1], Y], dim=1), take a small subbatch, choose a prefix length such as 128 or 160, and roll forward for H=8 or 16 steps. Each step runs the model on the current soft context, takes the final-position softmax distribution, records it, converts it to a soft token embedding with probs @ transformer.wte.weight, detaches that embedding, and appends it before the next step. Compare the resulting generated distributions to the held-out real continuation chunk[:, prefix_len:prefix_len + H] using simple fixed random-feature moments: unigram feature means, adjacent-bigram feature products, adjacent-repeat probability, and optional boundary-token mass if boundary characters exist. Add a small ramped Huber or MSE moment loss to the ordinary CE loss. Keep validation and default generation unchanged, but add diagnostics for ordinary validation loss, rollout moment error, free-run repeated n-gram rate, distinct n-gram fraction, generated character-frequency KL, train-val gap, total train time, and inference tokens per second. Compare against the baseline, teacher-forced future-sketch prediction, self-rollout unlikelihood, and a shuffled-future-moment control across shakespeare_char, enwik8, and text8.
