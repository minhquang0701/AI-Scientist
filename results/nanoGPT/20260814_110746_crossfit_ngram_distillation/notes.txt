# Title: Cross-Fit N-Gram Distillation for Leakage-Controlled Character Language Modeling
# Experiment description: Partition each dataset's train.bin into K contiguous folds, for example K=8. Before training, scan train.bin once to build capped suffix-to-next-character count tables for short suffix lengths such as 2 and 4. For each retained high-support suffix, store total next-character counts and compact per-fold counts, so the teacher for a sampled training window can subtract the fold containing that window. Modify get_batch() to return sampled offsets and fold ids. Train with ordinary next-character cross-entropy every iteration. After warmup_iters and every distill_interval iterations, build an out-of-fold n-gram teacher for supported batch positions using the longest retained suffix whose count after fold subtraction exceeds a threshold; optionally downweight high-entropy or low-support teacher distributions with a simple support gate. Add a small ramped KL or soft cross-entropy loss from this teacher distribution to the GPT logits. Compare CE-only training, full-train n-gram distillation, cross-fit n-gram distillation, and shuffled-teacher controls. Extend estimate_loss to report ordinary train and validation loss as the primary metric, teacher coverage, teacher-only validation NLL, validation loss by teacher-support bucket, train-val gap, expected calibration error, total train time, and unchanged generation tokens per second across shakespeare_char, enwik8, and text8.
