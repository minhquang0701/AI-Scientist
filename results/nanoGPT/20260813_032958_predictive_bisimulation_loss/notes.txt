# Title: Predictive Bisimulation Loss for Stable Autoregressive Belief Updates
# Experiment description: Keep the GPT architecture, data loader, evaluation path, and generation code unchanged. In the training loop, compute the ordinary next-character cross-entropy from logits as usual. Add a predictive_bisimulation_loss(logits, targets, max_positions=192, pred_temperature=2.0, pair_temperature=0.05, top_neighbors=4) helper used only after warmup_iters every bisim_interval iterations. The helper samples valid positions t < block_size - 1, computes detached current predictive distributions from logits[:, :-1, :] / pred_temperature, and forms neighbor pairs only when the observed next character targets[:, t] is identical and the current predictive distributions are among each other’s nearest neighbors by Jensen-Shannon distance. It then adds a small weighted Jensen-Shannon penalty between the trainable successor predictive distributions at t + 1 for those pairs, with all pair weights detached. Optimize total_loss = ce_loss + lambda_bisim * bisim_loss, ramping lambda_bisim conservatively to 0.01, 0.02, or 0.05. Extend estimate_loss to report ordinary train and validation loss as the primary metric, validation bisimulation loss, successor divergence for matched predictive states, expected calibration error, train-val gap, total train time, and unchanged inference tokens per second. Compare against the baseline, random matched-token pairs, shuffled-successor targets, and a static predictive-distribution smoothing control across shakespeare_char, enwik8, and text8.
