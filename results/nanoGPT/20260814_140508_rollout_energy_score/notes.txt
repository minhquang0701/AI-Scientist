# Title: Rollout Energy Scoring for Sequence-Calibrated Character Language Models
# Experiment description: Modify GPT.forward to optionally accept inputs_embeds while preserving the default idx path for ordinary training, evaluation, and generation. Add a rollout_energy_score_loss helper used only after warmup_iters every rollout_interval iterations. On a small subbatch, reconstruct chunks as torch.cat([X[:, :1], Y], dim=1), choose a prefix length such as 128 or 160, and roll forward for a short horizon H=8. Generate M=2 stochastic soft continuations using Gumbel-softmax or temperature-softmax samples from the model logits; at each rollout step, record the differentiable token probability vector for the auxiliary loss, but detach the soft token embedding fed into the next step to keep memory and instability low. Map predicted soft tokens and real continuation tokens into fixed random feature summaries, including unigram features, adjacent-bigram sketches, repeat indicators, and optional boundary-token features when available. Train every iteration with ordinary next-character cross-entropy, and on rollout iterations add a ramped energy-score auxiliary: mean distance from each rollout summary to the real continuation summary minus 0.5 times the distance between rollout summaries, with lambda_energy capped around 0.02 to 0.10. Extend evaluation with rollout energy score on validation prefixes, repeated n-gram rate, distinct n-gram fraction, generated character-frequency KL, expected calibration error, ordinary validation loss, total train time, and inference tokens per second. Compare against the CE-only baseline, teacher-forced future-feature prediction, rollout moment matching without the sample-sample diversity term, and a shuffled-continuation control across shakespeare_char, enwik8, and text8.
