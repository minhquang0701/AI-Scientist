# Title: Crop-Origin Marginalization for Boundary-Robust Autoregressive Language Modeling
# Experiment description: Modify get_batch() to optionally sample contiguous chunks of length block_size + max_shift + 1, with max_shift values such as 32 or 64. On ordinary iterations, train exactly as the baseline with standard next-character cross-entropy. After warmup_iters, every marginal_interval iterations, build two or three overlapping views from the same chunk, for example shifts 0, 32, and 64, run the model on each view, and align true-target log probabilities for absolute target positions that are present in all views. Add a small ramped auxiliary loss equal to the negative log-mean-exp of the aligned true-target log probabilities across crop origins, while retaining the canonical shift-0 cross-entropy as the main loss. Extend estimate_loss() to report ordinary validation loss, validation loss by distance from the left crop boundary, boundary-to-interior loss gap, multi-origin marginal validation loss, short-context validation losses, total train time, and unchanged single-view generation tokens per second. Compare against the baseline, overlap-KL consistency, and a random-shift CE control across shakespeare_char, enwik8, and text8.
